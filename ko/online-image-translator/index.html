온라인 이미지 번역기 소개

온라인 이미지 번역기는 무료 오픈 소스 웹 도구로, 만화, 스크린샷, 사진 등 이미지 속 텍스트를 브라우저에서 바로 번역할 수 있습니다. 설치가 필요하지 않습니다.

작동 방식

로컬 PaddleOCR 모드:OCR이 전적으로 브라우저에서 실행되며(PaddleOCR을 WebAssembly로 컴파일), 번역에는 무료 MyMemory API 또는 OpenAI 호환 API(ChatGPT, DeepSeek 등)를 사용하므로 서버가 필요하지 않습니다.

ImageTrans 서버 모드:ImageTrans 서버(공용 서버 또는 자체 서버)에 연결하여 OCR 인식, 번역, 텍스트 렌더링을 한 번에 처리합니다.

이 프로젝트는 MIT 라이선스로 공개되어 있습니다. GitHub에서 소스 코드를 확인하고, 문제를 보고하거나 기여할 수 있습니다.
