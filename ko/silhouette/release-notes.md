## v1.6.2 (2026/08/30)

* ChatGPT 및 DeepSeek 번역 플러그인 업데이트
* 무료 LLM 플러그인 추가
* 텍스트를 분할할 때 번역문이 잘못하여 원문 텍스트를 사용하는 문제 수정


## v1.6.1 (2026/05/01)

* FunASR 추가
* 인식 결과가 숫자만 있을 때 내보낸 SRT 파싱에 실패하는 문제 수정
* 오디오 파일을 재생할 때 자막 글꼴 크기 환경 설정이 적용되지 않는 문제 수정
* 텍스트 상자에서 스페이스 키를 누르거나 마우스를 움직이면 포커스가 전환되는 문제 수정

## v1.6.0 (2026/04/28)

* Qwen3-ASR 추가
* 행 병합 옵션 추가: 문장 부호 기준, 시간 확인 여부
* 자막 하단 오프셋 환경 설정
* ASR 플러그인이 설치되어 있거나 실행 중인지 확인
* 오디오 파일 열기 버그 수정

## v1.5.5 (2025/10/21)

* Windows 7 지원
* VLC 로드 실패 시 오류 보고
* 파형을 활성화하지 않았을 때 파형을 클릭하여 이동하는 데 실패하는 문제 수정
* 재생을 일시 정지하고 행을 선택한 후 진행률 따라가기 상태가 복원되지 않는 문제 수정

## v1.5.4 (2025/10/19)

* 동영상을 열지 않았을 때 재생 영역을 마우스 오른쪽 버튼으로 클릭하면 오류가 나는 문제 수정
* 기본적으로 VLC 포함

## v1.5.3 (2025/07/06)

* 빨리 감기 시간 설정 추가
* 각 행을 재생하는 메뉴 항목 추가
* 버그 수정

## v1.5.2 (2025/05/18)

* 자막 제거 동영상 생성기 추가
* 파형을 클릭하여 진행률을 이동하는 기능 지원

## v1.5.1 (2025/05/11)

* 선택한 부분을 재생할 때 "진행률 따라가기" 비활성화
* 정렬기가 텍스트의 일부만 정렬하는 기능 지원
* 자막 환경 설정 추가: 형식, 동영상 너비에 맞춤
* FFmpeg 실행기 추가
* 새로운 내보내기 옵션: 하드 자막이 포함된 동영상(FFmpeg로 압축)

## v1.5.0 (2025/05/02)

* 새 기능: 행 분할과 행 병합
* 문장 분할기에 SRX 기반 자동 문장 분할 버튼 추가
* 분할 및 병합 모드 추가
* 빠른 번역 버튼 추가
* 자막 텍스트의 CSS 설정 추가
* Whisper로 전체 파일을 인식할 때 추가 매개변수가 전달되도록 수정
* Whisper의 오류 메시지 개선

## v1.4.1 (2025/04/04)

* TXT로 가져오기 및 내보내기 옵션 추가
* SRT에서 텍스트를 가져오는 관련 옵션 추가
* DeepSeek 플러그인 추가
* ChatGPT의 타임아웃을 2분으로 증가

## v1.4.0 (2025/03/01)

* 간체/번체 변환 추가
* 프레임 추출기 추가
* 이동 후 재생 관련 메뉴 항목 추가
* 선택한 부분을 인식하는 오른쪽 클릭 메뉴 항목 추가
* Whisper의 중국어 언어 코드 문제 수정

## v1.3.0 (2025/02/22)

* 인식된 타임라인과 기존 텍스트를 정렬하는 정렬기 추가(음성-텍스트 정렬)
* XLIFF 가져오기 및 내보내기 지원
* 이중 언어 SRT 가져오기 지원
* 추가 음성 인식 매개변수 프로젝트 설정 추가
* 원문과 번역문을 교환하는 메뉴 항목 추가
* 새로운 음성 인식 옵션: 오디오 분할 안 함
* Windows에서 처음 시작할 때 GPU 사용 여부를 묻는 기능
* 기타 버그 수정

## v1.2.0 (2025/02/09)

* 선택한 부분을 정확하게 재생하는 환경 설정 추가
* 음성 입력 추가
* 문장 분할기 추가
* 일괄 번역기가 SRT 내보내기 지원
* 타임라인을 일괄 조정하기 전에 조정할 범위를 먼저 묻는 기능
* 파형 그리기의 오프셋 문제 수정
* 기타 버그 수정

## v1.1.0 (2025/02/04)

* 자막 글꼴 크기 환경 설정 추가
* GPU 사용 환경 설정 추가
* 프롬프트 프로젝트 설정 추가
* 일괄 번역 추가
* 타임라인 전체 오프셋 기능 추가
* 선택한 행을 위로/아래로 이동하는 메뉴 항목 추가
* 진행률 텍스트에 hh:mm:ss 형식 사용
* macOS의 단축키에 커맨드 키 사용
* 삭제 키로 선택한 행을 빠르게 삭제하는 기능 지원
* 선택한 행 뒤에 새 행 삽입
* macOS와 Linux에서 경로에 공백을 넣지 않도록 안내
* 자막 가운데 정렬 문제 수정
* 현지화 문제 수정
