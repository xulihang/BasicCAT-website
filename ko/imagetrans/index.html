ImageTrans는 컴퓨터 보조 이미지 텍스트 전사 및 번역 도구로, OCR 기술을 사용해 텍스트를 자동으로 찾아 인식하고, 원문을 자동으로 지운 뒤 번역문을 다시 채워 넣습니다. 또한 만화를 위해 설계된 텍스트 영역 병합 및 감지 알고리즘을 갖추고 있습니다.

ImageTrans는 포스터나 만화를 번역하는 이미지 번역기로 사용할 수 있을 뿐만 아니라, 이미지 읽기, 텍스트 전사, 스크린샷 OCR 번역, PDF를 마크다운으로 변환 및 번역, 스캔 문서의 이중 레이어 검색 가능 PDF 생성, 딥러닝 라벨링 등의 용도로도 활용할 수 있습니다.

ImageTrans는 제 석사 학위 논문의 성과물입니다: 만화 번역 보조 도구의 설계와 구현.

ImageTrans 받기

핵심 기능

🔍

텍스트 영역 정확하게 찾기

자연 장면 텍스트 감지, 객체 감지, 휴리스틱 등 여러 방법을 지원하며, 만화 말풍선을 위해 설계된 텍스트 영역 병합 및 감지 알고리즘을 갖추고 있습니다.

📖

다중 엔진 OCR 인식

다양한 OCR 엔진과 사용자 정의 플러그인을 지원하며, 세계 주요 언어를 커버합니다. 세로쓰기 중·일문 인식을 지원하고, 레이아웃 분석으로 읽기 순서를 결정합니다. 대규모 언어 모델을 활용해 OCR 정확도를 교정·개선할 수 있습니다.

🌐

번역

기계 번역: 다양한 기계 번역 엔진과 AI 대규모 언어 모델(ChatGPT, Gemini, DeepSeek 등)을 지원합니다. 문맥 정보를 활용해 번역 품질을 높입니다.

보조 기능: 여러 결과 나란히 비교, 번역 메모리, 말뭉치 검색, 용어 관리, 후리가나와 병음 주석, 그리고 만화 의성어 검색 시스템을 제공합니다.

🧹

텍스트 제거

이진화, PatchMatch, Lama Inpaint, Gemini Nano Banana 등의 알고리즘과 AI 모델로 텍스트 마스크를 생성해 텍스트를 제거합니다. 텍스트를 제거할 때 만화 스크린톤을 보존합니다.

🎨

텍스트 조판

  • 글꼴 크기 자동 조정
  • 공백으로 단어를 구분하는 언어의 줄바꿈 최적화(일→영 번역 등)
  • 구두점 줄머리·줄끝 회피 처리
  • 서식 있는 텍스트와 글꼴 스타일(Word와 유사한 스타일 시스템)
  • 텍스트 색상 감지
  • 회전 각도 감지
  • 세로쓰기 조판
🖌️

PSD 내보내기

결과를 Photoshop PSD 파일로 저장하며, 텍스트가 레이어로 분리되어 디자이너가 후처리하기 편리합니다.

📦

일괄 처리

수백 장의 이미지를 한 번에 처리합니다. 사용자 정의 작업 흐름, 명령줄 호출, 다중 프로세스 병렬 처리를 지원해 고속으로 대량 결과물을 만들어 냅니다.

🖥️

직관적이고 강력한 인터페이스

시각적 편집기와 실시간 미리보기를 제공합니다. OCR, 번역, 이미지 보정, 레터링, 검색 및 바꾸기, 사용자 정의 워크플로 등 다양한 작업을 단계별로 실행할 수 있습니다 — 통일된 인터페이스에서 강력하면서도 사용하기 쉽습니다.

더 많은 기능

📄

PDF 번역과 Markdown 변환

PDF를 번역해 Markdown으로 변환하고, 원문·번역문·대역으로 출력할 수 있으며 다단 논문, 수식, 표, 각주 등의 구조를 유지합니다. 검색 가능한 이중 레이어 PDF를 생성합니다.

🖥️

화면 실시간 번역

화면의 임의 영역을 실시간으로 캡처해 번역합니다. 내용 변화를 자동으로 감지하고 번역 메모리 즉시 일치를 지원합니다.

🎬

동영상 하드코딩 자막 추출

동영상의 하드코딩 자막을 추출합니다. 빠른 OCR 텍스트 감지를 활용해 빠르고 정확하며, SRT 자막 파일로 출력합니다.

📷

문서 스캔과 이미지 개선

TWAIN / WIA / SANE / ICA / eSCL 통합 스캔을 지원합니다. 스캔한 책을 정리하고 기울기를 보정하며 개선해 최상의 이미지 전처리 효과를 얻습니다.

사용 편의성

⌨️

키보드 단축키

거의 모든 작업이 키보드 단축키를 지원하므로 마우스로 자주 오갈 필요 없이 작업 흐름이 빠르고 효율적입니다.

💻

명령줄과 API 호출

명령줄을 통해 ImageTrans를 호출해 자동화 작업을 수행할 수 있습니다. API 서버로 실행해 HTTP로 번역 서비스를 제공하므로 어떤 애플리케이션이나 서비스와도 손쉽게 통합할 수 있습니다.

⚙️

사용자 정의 워크플로

감지, OCR, 번역, 렌더링 등 처리 단계를 자유롭게 조합해 필요에 맞는 자동화 워크플로를 구성할 수 있습니다.

🤖

AI Agent 통합

ImageTrans Skills를 통해 AI Agent가 ImageTrans를 호출할 수 있습니다 — 구조화된 스킬 정의로 LLM 기반 에이전트가 번역 작업을 프로그래밍 방식으로 수행할 수 있습니다.

📐

스마트 정렬과 검색·바꾸기

텍스트 상자를 이동할 때 정렬 안내선을 표시하고, 선택한 상자를 원문 텍스트 위치에 일괄 정렬하며, 검색 및 바꾸기 기능을 내장하고 있습니다. 전자상거래 이미지 번역 등의 시나리오에 적합합니다.

크로스 플랫폼 · 낮은 하드웨어 요구 사항

💻

Windows · macOS · Linux

Windows 7+, macOS 10.11+ 및 Linux를 지원합니다. 서버로도 실행할 수 있어 모바일 기기로 이미지를 스캔하고 번역할 수 있습니다.

⚡

가볍고 효율적

Java 실행 환경과 모델을 포함해 약 400 MB이며, 오래되었거나 저사양인 기기에서도 실행됩니다. 오프라인 작업을 지원하므로 인터넷 연결이 필요 없습니다.

🔌

상호 운용성

PSD 내보내기, Excel/Word/XLIFF 데이터 교환, LabelPlus 프로젝트 변환을 지원하며, Chrome 확장 프로그램과 함께 사용해 웹페이지의 이미지를 번역할 수 있습니다.
