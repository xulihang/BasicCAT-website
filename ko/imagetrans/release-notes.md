## v6.5.0 (2026/09/11)

* JRE를 [JRE26](https://download.bell-sw.com/java/26.0.2.1+1/bellsoft-jre26.0.2.1+1-windows-amd64-full.zip)(으)로 업데이트
* 고충실도 JPEG 내보내기 설정 추가
* 텍스트 방향을 감지하고 회전 각도를 설정하는 사용자 정의 워크플로 추가
* 이미지가 아니라 텍스트 영역의 노드를 회전
* 번역 모드에서 선택 영역을 정렬할 때 번역문 영역의 위치만 조정
* RTL 언어용 컨트롤은 단순히 오른쪽 정렬을 설정하는 대신 NodeOrientation을 RIGHT_TO_LEFT로 설정
* 서버 다운로드 옵션 추가
* 네트워크 요청이 느릴 때 다운로드를 취소해도 실패한 파일이 제때 삭제되지 않는 문제 수정
* 새 프로젝트를 만들 때 TextArea 스타일 갱신을 잊는 문제 수정
* 아랍어와 비아랍어가 섞인 단어를 병합할 때의 순서 수정
* 아랍어 조판 시 RTL이 활성화되지 않는 문제 수정
* 내보낸 PDF의 텍스트가 회전을 지원하지 않는 문제 수정
* 회전된 영역의 텍스트가 가운데를 기준으로 회전하지 않는 문제 수정
* 회전된 영역의 크기 조정 수정
* CJK 세로쓰기를 비활성화할 때 오류가 발생하는 문제 수정
* rapidOCR의 순수 아랍어 숫자 처리 수정
* 아랍어 PDF 생성 시 순수 아랍어 숫자 처리 수정

## v6.4.0 (2026/09/03)

* PDF 내보내기 옵션의 기본 글꼴 선택 개선
* PDF 내보내기의 자동 글꼴 검색 기능에 Windows 사용자 폴더의 글꼴 폴더 검색 추가
* 내보낸 세로쓰기 텍스트 PDF의 텍스트 간격 개선
* 프로젝트 설정에 글꼴 스타일이 없을 때 중·일문 PDF를 내보내면 텍스트 방향을 자동 감지
* 사용자 정의 워크플로에서 처리 시간 집계 지원
* 모든 기본 번역을 바이두로 변경
* 내보낸 세로쓰기 중국어 번역판 PDF의 텍스트 높이가 맞지 않는 문제 수정
* RapidOCR이 아랍어 숫자를 잘못 뒤집는 문제 수정
* 아랍어 PDF 생성 시 아랍어 숫자를 잘못 뒤집는 문제 수정

## v6.3.3 (2026/08/28)

* 겹치는 영역을 병합하는 사용자 정의 워크플로 추가
* 포르투갈어(브라질) 언어 옵션 추가
* 객체 감지 기반 패널 감지에서 `model.json`에 사용할 카테고리 이름(`class_names_to_use_for_panel`)을 정의하는 기능 지원
* 새 프로젝트를 만들 때 언어를 선택하지 않으면 오류가 발생하는 문제 수정
* 세로쓰기 텍스트가 포함된 PDF를 내보낼 때 오류가 발생하는 문제 수정

## v6.3.2 (2026/08/21)

* 텍스트 제거기를 열면 프로젝트 설정의 제거 방식이 로드되도록 변경
* 복잡한 배경 마스크 생성이나 이미지 인페인팅 방식을 설정한 경우 마스크 편집기나 텍스트 제거기를 열 때 영역별 선택 방식을 사용
* 텍스트 방향 감지로 텍스트 스타일을 설정하는 것은 대상 언어가 세로쓰기를 지원할 때만 실행
* 인증서 생성기가 IP를 미리 가져오고 소프트웨어의 cert 폴더를 기본 폴더로 사용
* 인증서 생성기가 설정한 IP를 올바르게 사용하지 않는 문제 수정

## v6.3.1 (2026/08/13)

명령줄로 프로젝트를 열 때 UI 조정이 끝나고 OCR 언어 선택이 완료될 때까지 기다리지 않고 후속 작업을 실행하던 문제 수정

## v6.3.0 (2026/08/06)

* 설치 패키지에 int8 양자화 고정 512x512 크기의 Lama Inpaint ONNX 모델을 기본 포함
* 설치 패키지에서 MIGAN Inpaint 제거
* 설치 패키지에서 이미지 언어 분류 모델 제거
* CG 템플릿의 Lama Inpaint 활용 개선
* RF-DETR 모델 지원 추가
* 회전하지 않은 영역을 제거하는 사용자 정의 워크플로 추가
* 단어가 이 길이보다 크면 분할할 수 있는 프로젝트 설정 추가
* 원격 모델 다운로드에서 SHA256 검증 지원
* RapidOCR이 네트워크에서 모델을 자동으로 다운로드하고, 언어를 전환할 때 모델 미설치 안내를 표시하지 않도록 변경
* 설치 패키지에 RapidOCR의 태국어와 아랍어 사전을 기본 포함
* 영역별로 텍스트를 제거할 때 영역이 겹치면 병합한 뒤 영역별로 제거하여 겹침으로 인해 제거 효과가 떨어지는 문제 개선
* mangaOCR로 전체 이미지를 인식할 때 mit48px OCR 모델이 없으면 rapid로 긴 띠 모양 텍스트를 인식
* 마스크 생성과 텍스트 제거 시 이미지가 복잡한지 확인하는 ROI가 일치하지 않는 문제 수정
* 사전 번역이 텍스트 없는 이미지를 건너뛰지 못하던 버그 수정

## v6.2.2 (2026/08/01)

* 객체 감지의 영어 번역에서 불필요한 공백 제거
* 사전 번역이 텍스트 없는 이미지를 건너뛰도록 변경

* 서버가 번역된 이미지를 업로드하기 전에 실행 상태를 false로 설정할 수 있는 문제 수정

## v6.2.0 (2026/07/26)

* 범용 서버 템플릿 추가
* 범용 언어 쌍 템플릿으로 프로젝트를 만들 때 적절한 OCR을 자동 선택
* 표 분류에서 셀을 감지하는 사용자 정의 워크플로 추가
* 텍스트 영역이 어느 패널에 속하는지 판정하는 모든 로직 재작성
* 텍스트 마스크를 사용해 복잡한 배경 이미지 판정 개선
* Deepseek 기본 모델 이름을 deepseek-v4-flash로 변경
* 패널 감지와 번역 워크플로에서 각 항목에 매개변수를 정의할 수 있도록 지원
* 마스크 생성의 반전 영역 판정 개선
* 서버에서 원격 서버 비밀번호(ws_secret) 설정 지원
* 서버에서 언어 전용 프로젝트 설정(src.json) 로드 지원
* 서버의 이미지 자동 정리 기능에 썸네일 정리 추가
* oneocr의 onnxruntime 버전 충돌 문제 수정

* 서버 사용자 정의 워크플로가 이전에 내보낸 같은 이름의 이미지를 그대로 사용하는 문제 수정

* 명령줄로 프로젝트를 열어 사용자 정의 워크플로를 실행할 때 프로젝트의 preferences.conf, settings.json, setOCRBasedOnLang을 읽어 템플릿으로 프로젝트를 만드는 모드와 일치하도록 변경
