**최종 업데이트: 2026년 7월 19일**

ImageTrans는 사용자의 개인정보를 존중합니다. 본 개인정보 처리방침은 ImageTrans 브라우저 확장 프로그램이 사용자의 데이터를 어떻게 처리하는지 설명합니다.

## 이미지

본 확장 프로그램은 사용자가 번역하기로 명시적으로 선택한 이미지만 처리합니다.

번역을 시작하면 선택한 이미지가 사용자가 구성한 번역 서버로 업로드됩니다. 서버는 이미지를 처리한 후 번역 결과를 반환합니다.

본 확장 프로그램은 사용자의 조작 없이 어떤 이미지도 업로드하지 않습니다.

## 개인정보를 수집하지 않습니다

본 확장 프로그램은 다음 정보를 수집, 저장 또는 전송하지 않습니다.

- 브라우징 기록
- 개인 식별 정보
- 비밀번호
- 결제 정보
- 이메일
- 연락처
- 위치 데이터

## 데이터 저장

이미지는 번역 요청을 처리하는 동안에만 번역 서버에 일시적으로 저장될 수 있으며, 처리가 완료되면 즉시 삭제됩니다.

## 데이터 공유

이미지는 요청된 번역을 수행하기 위한 번역 서버로만 전송됩니다.

사용자의 구성에 따라 해당 서버는 다음 중 하나일 수 있습니다.

- ImageTrans 공식 서버
- 사용자가 직접 구축한 ImageTrans 서버

직접 구축한 서버를 사용하는 경우, 업로드된 이미지의 처리 및 보관 방식은 서버 운영자가 결정합니다.

본 확장 프로그램은 사용자 데이터를 판매하거나 광고주 또는 기타 제3자에게 공유하지 않습니다.
