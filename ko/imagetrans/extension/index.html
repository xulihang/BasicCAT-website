ImageTrans 브라우저 확장

클릭 한 번으로 웹페이지의 모든 이미지를 번역하며, 만화, 포스터, 스크린샷 등의 상황에 맞게 설계되었습니다. 마우스 오른쪽 버튼을 클릭하거나 단축키를 사용하면 번역 결과를 바로 얻을 수 있습니다.

ImageTrans 브라우저 확장이란 무엇인가요?

ImageTrans 브라우저 확장은 AI 기반 이미지 번역 기능을 여러분의 브라우저로 직접 가져옵니다. 웹페이지에 있는 이미지(만화, 포스터, 스크린샷, 브로셔 등)의 텍스트를 감지하고 자동으로 번역된 버전으로 바꿔 줍니다.

PaddleOCR과 ImageTrans 데스크톱 앱 백엔드를 기반으로, 이 확장 프로그램은 최첨단 OCR 기술과 신경망 기계 번역을 결합하여 정확하고 문맥에 맞는 번역 결과를 제공합니다.

주요 기능

🖱️

마우스 오른쪽 버튼으로 번역

웹페이지에서 이미지를 마우스 오른쪽 버튼으로 클릭하고 '이미지 번역'을 선택하면 번역된 버전을 즉시 확인할 수 있습니다.

⌨️

키보드 단축키

Ctrl+Shift+F를 누르면 커서 아래에 있는 이미지를 번역할 수 있어 빠르고 효율적입니다.

🔄

자동 번역

자동 번역을 활성화하면 페이지를 불러올 때 이미지가 자동으로 번역됩니다. 긴 만화를 읽을 때 아주 적합합니다.

📸

스크린샷 번역

브라우저에서 화면 영역을 캡처하여 번역할 수 있으며, 다운로드할 수 없는 이미지를 번역하거나 이미지의 일부 영역만 번역할 때 적합합니다.

🤖

유연한 번역 옵션

모든 OCR 백엔드(ImageTrans 또는 PaddleOCR)를 OpenAI 호환 API(ChatGPT, Gemini, DeepSeek) 또는 내장 번역 엔진과 함께 사용하여 최상의 번역 결과를 얻을 수 있습니다.

🀄

발음 표기

일본어 텍스트에는 가나를, 중국어 텍스트에는 병음을 표시합니다. 언어 학습자에게 든든한 조력자입니다.

사용 방법

  1. 확장 프로그램 설치 Chrome 웹 스토어, Firefox 부가 기능 또는 Microsoft Edge 부가 기능 스토어에서 추가합니다. 📱 모바일: iOS에서는 Orion 브라우저를 사용하여 Chrome 또는 Firefox 확장 프로그램을 실행할 수 있습니다. Android에서는 Firefox for Android, Edge 또는 Kiwi 브라우저를 사용할 수 있습니다.
  2. 백엔드 구성 ImageTrans 서버에 연결하거나, 내장 PaddleOCR을 사용하거나, 직접 OpenAI 호환 API 키를 설정합니다.
  3. 번역 시작 이미지를 마우스 오른쪽 버튼으로 클릭 → '이미지 번역'. 자동 번역을 켜면 페이지를 불러올 때 모든 이미지가 자동으로 번역됩니다. 스크린샷 기능으로 화면의 일부를 번역하거나, 촬영 기능으로 사진을 찍어 실시간으로 번역할 수도 있습니다. 이제 완료입니다!

작동 방식

🔌 ImageTrans 데스크톱 버전과 함께 사용(권장)

  • ImageTrans가 전체 과정을 담당합니다: 감지 → OCR → 텍스트 제거 → 번역 → 렌더링
  • 최고의 정확도, 가장 폭넓은 언어 지원, 풍부한 편집 기능
  • 확장 프로그램이 이미지를 ImageTrans로 보내 처리한 뒤 완성된 결과물을 바로 표시합니다
  • ImageTrans가 로컬 또는 서버에서 실행 중이어야 합니다

🧩 ImageTrans에 의존하지 않음(브라우저에서만 실행)

  • 확장 프로그램이 프런트엔드에서 전체 과정을 독립적으로 수행합니다: OCR(PaddleOCR) → 번역 → 렌더링
  • 서버나 소프트웨어 설치가 필요 없습니다 — 완전히 자체적으로 동작합니다
  • 무료이며 개인정보를 보호합니다
  • 정확도, 속도, 언어 옵션은 다소 제한적입니다

번역 옵션

다음 번역 방식은 두 모드에서 모두 사용할 수 있습니다. ImageTrans와 함께 OpenAI 호환 API를 사용할 때는 ImageTrans가 OCR만 담당하고, 번역과 렌더링은 확장 프로그램이 프런트엔드에서 수행합니다.

🌐 ImageTrans 내장 번역

  • ImageTrans에 연결할 때 사용할 수 있습니다
  • 다양한 번역 엔진 지원(Google, DeepL, Baidu 등)
  • 번역 메모리, 용어 관리, 코퍼스 검색 기능을 포함합니다

🤖 OpenAI 호환 API

  • ChatGPT, Gemini, DeepSeek 또는 호환되는 모든 API 사용
  • ImageTrans와 함께 또는 없이 사용 가능 — 자신의 API 키를 사용합니다
  • 유연한 사용자 지정 프롬프트로 더욱 세밀한 번역을 구현합니다
  • ImageTrans와 함께 사용할 경우: ImageTrans는 OCR만 담당하고, 확장 프로그램이 번역과 렌더링을 담당합니다

🆓 MyMemory(무료)

  • 키가 필요 없는 무료 기계 번역 API
  • 빠르고 임시적인 번역이 필요할 때 적합합니다

ImageTrans 데스크톱 버전 소개

ImageTrans는 기능이 완비된 컴퓨터 지원 이미지 번역 데스크톱 소프트웨어입니다. 브라우저 확장 프로그램은 빠른 즉석 번역에 적합하고, ImageTrans 데스크톱 버전은 전체 번역 워크플로를 완전히 제어할 수 있게 해 줍니다.

🎛️

강력한 사용자 지정 기능

각 단계를 세밀하게 조정할 수 있습니다. 다양한 OCR 엔진 중에서 자유롭게 선택하고, 감지 알고리즘을 구성하고, 렌더링 매개변수를 사용자 지정하여 필요에 정확히 맞출 수 있습니다.

✏️

수동 편집

텍스트 영역 조정, OCR 결과 수정, 번역 내용 편집, 텍스트 위치 미세 조정 — 자동화가 충분하지 않을 때 모든 것을 직접 제어할 수 있습니다.

🎨

PSD 내보내기

번역된 이미지를 Photoshop(PSD) 파일로 내보냅니다. 텍스트가 레이어별로 분리되어 있어 디자이너에게 전달하여 후처리하기 편리합니다.

📦

일괄 처리

한 번에 수백 장의 이미지를 번역합니다. Excel, Word 또는 XLIFF를 통한 데이터 가져오기·내보내기를 지원하여 다른 번역 도구와 원활하게 연동됩니다.

무엇을 번역할 수 있나요?

📚

만화와 웹툰

어떤 웹사이트에서든 번역된 만화, 웹툰, 팬 창작물을 읽을 수 있습니다. 이 확장 프로그램은 만화 말풍선과 텍스트 배치에 맞게 최적화되어 있습니다.

📋

포스터와 브로셔

외국어 홍보 자료, 인포그래픽, 광고 내용을 빠르게 이해할 수 있습니다.

📱

스크린샷과 사진

스크린샷 기능으로 이미지의 일부 영역을 번역하거나, 웹페이지에서 다운로드할 수 없는 이미지를 번역할 수 있습니다 — 모든 것이 브라우저 안에서 완료됩니다.

📝

이미지에서 텍스트 추출

번역 없이 이미지에서 텍스트를 추출합니다. OCR 작업, 데이터 입력, 접근성 관련 상황에 적합합니다.
