Vous pouvez contribuer à l'amélioration d'ImageTrans de la manière suivante :

1. Traduire la documentation

	La documentation d'ImageTrans est réalisée avec Sphinx et hébergée sur readthedocs.

	Dépôt du code de la documentation : <https://github.com/xulihang/ImageTrans-docs>

	Il faut utiliser l'outil de localisation de Sphinx pour extraire les fichiers po et les traduire.

2. Traduire l'interface du logiciel

	ImageTrans utilise [B4XLocalizator](https://www.b4x.com/android/forum/threads/b4x-localizator-localize-your-b4x-applications.68751/) pour la localisation, et il faut traduire le fichier strings.xlsx. Une fois la traduction terminée, convertissez-le en strings.db pour que le logiciel puisse l'utiliser.
	
	strings.xlsx est téléchargeable ici : <https://github.com/xulihang/ImageTrans_l10n_en/releases/tag/strings>

3. Développer des plugins

	ImageTrans utilise ABPlugin pour développer des plugins. Code des plugins existants : <https://github.com/xulihang/ImageTrans_plugins>
	
4. Proposer des suggestions

	Rendez-vous sur la [page des issues](https://github.com/xulihang/ImageTrans-docs/issues) de la documentation pour proposer vos suggestions.
