ImageTrans は、コンピュータ支援による画像の文字起こしと翻訳のためのツールです。OCR 技術を使って文字を自動的に検出・認識し、原文を自動で消去して訳文を流し込みます。さらに、漫画向けに設計された文字領域の結合・検出アルゴリズムを備えています。

ImageTrans は、ポスターや漫画を翻訳する画像翻訳ツールとしてだけでなく、画像の閲覧、文字起こし、スクリーンショットの OCR 翻訳、PDF から Markdown への変換と翻訳、スキャン文書から検索可能な二層 PDF の生成、ディープラーニング用のアノテーションなどの用途にも利用できます。

ImageTrans は、私の修士論文の成果です：漫画翻訳支援ツールの設計と実装。

ImageTrans を入手する

主な機能

🔍

文字領域を正確に検出

自然シーンの文字検出、物体検出、ヒューリスティックなど複数の手法に対応し、漫画の吹き出し向けに設計された文字領域の結合・検出アルゴリズムを備えています。

📖

複数エンジンによる OCR 認識

各種の OCR エンジンとカスタムプラグインに対応し、世界の主要言語をカバーしています。縦書きの中国語・日本語の認識に対応し、レイアウト解析によって読み順を判定します。大規模言語モデルを活用して OCR の精度を改善することもできます。

🌐

翻訳

機械翻訳：各種の機械翻訳エンジンと AI 大規模モデル（ChatGPT、Gemini、DeepSeek など）に対応しています。文脈情報を活用して翻訳品質を高めることができます。

支援機能：複数の翻訳結果の並列比較、翻訳メモリ、コーパス検索、用語管理、ルビやピンインの注釈付け、そして漫画のオノマトペ検索システム。

🧹

文字の除去

二値化、PatchMatch、Lama Inpaint、Gemini Nano Banana などのアルゴリズムや AI モデルによって文字マスクを生成し、文字を除去します。文字を除去する際に漫画のスクリーントーンを保持することもできます。

🎨

文字の組版

  • フォントサイズの自動調整
  • スペースで区切る言語の改行を最適化（日本語から英語への翻訳時など）
  • 句読点の禁則処理
  • リッチテキストとフォントスタイル（Word のようなスタイルシステム）
  • 文字色の検出
  • 回転角度の検出
  • 縦書き文字の組版
🖌️

PSD の書き出し

処理結果を Photoshop の PSD ファイルとして保存できます。文字がレイヤーごとに分かれているため、デザイナーによる後処理が容易です。

📦

バッチ処理

数百枚の画像を一度に処理できます。カスタム操作フロー、コマンドラインからの呼び出し、マルチプロセス並列処理に対応し、高速な大量出力を実現します。

🖥️

直感的で強力なインターフェース

ビジュアルエディターによるリアルタイムプレビュー。OCR、翻訳、画像加工、文字入れ、検索置換、カスタムワークフローなど各種の操作を順を追って実行できます。統一されたインターフェースで、高機能かつ使いやすい設計です。

その他の機能

📄

PDF の翻訳と Markdown への変換

PDF を翻訳して Markdown に変換し、原文・訳文・対訳のいずれかで出力できます。多段組の論文、数式、表、脚注などの構造も保持します。検索可能な二層 PDF を生成することもできます。

🖥️

画面のリアルタイム翻訳

画面の任意の領域をリアルタイムでキャプチャして翻訳します。内容の変化を自動的に検出し、翻訳メモリの即時マッチングにも対応しています。

🎬

動画のハードサブ（焼き込み字幕）抽出

動画に焼き込まれた字幕を抽出します。高速な OCR 文字検出により、スピーディーかつ正確に処理し、SRT 字幕ファイルを出力します。

📷

文書のスキャンと補正

TWAIN / WIA / SANE / ICA / eSCL によるスキャン統合に対応しています。スキャンした書籍のクリーニング、傾き補正、画質向上を行い、最適な画像前処理を実現します。

使いやすさ

⌨️

キーボードショートカット

ほぼすべての操作にキーボードショートカットが用意されており、マウスに持ち替える手間なく、素早く効率的に作業できます。

💻

コマンドラインと API からの呼び出し

コマンドラインから ImageTrans を呼び出して自動処理を実行できます。API サーバーとして動作させ、HTTP 経由で翻訳サービスを提供できるため、あらゆるアプリやサービスと簡単に連携できます。

⚙️

カスタムワークフロー

検出、OCR、翻訳、レンダリングなどの処理ステップを自由に組み合わせて、ニーズに合った自動ワークフローを構築できます。

🤖

AI Agent との連携

ImageTrans Skills を通じて、AI Agent から ImageTrans を呼び出せます。構造化されたスキル定義により、LLM 駆動のエージェントがプログラム的に翻訳タスクを実行できます。

📐

スマートな位置合わせと検索置換

文字ボックスを移動すると位置合わせ用のガイドラインを表示し、原文の位置への一括整列や検索置換機能も備えています。EC サイトの画像翻訳などのシーンに適しています。

クロスプラットフォーム・低いハードウェア要件

💻

Windows · macOS · Linux

Windows 7 以降、macOS 10.11 以降、Linux に対応しています。サーバーとして動作させ、モバイル端末から画像をスキャンして翻訳することもできます。

⚡

軽量で高効率

Java 実行環境とモデルを含めて約 400 MB で、古い機器や低スペックな端末でも動作します。オフラインでも作業でき、ネット接続は不要です。

🔌

相互運用性

PSD の書き出し、Excel / Word / XLIFF でのデータ交換、LabelPlus プロジェクトの変換に対応し、Chrome 拡張機能と組み合わせてウェブページ内の画像を翻訳できます。
