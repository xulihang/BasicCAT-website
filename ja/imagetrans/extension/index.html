ImageTrans ブラウザ拡張とは？

ImageTrans ブラウザ拡張は、AI による画像翻訳機能をそのままお使いのブラウザに持ち込みます。ウェブページ内の画像（マンガ、ポスター、スクリーンショット、パンフレットなど）の文字を検出し、自動的に翻訳後のテキストに置き換えます。

PaddleOCR と ImageTrans デスクトップアプリのバックエンドを基盤として、最先端の OCR 技術とニューラル機械翻訳を組み合わせ、正確で文脈に合った翻訳結果を提供します。

主な機能

🖱️

右クリックで翻訳

ウェブページ上の任意の画像を右クリックし、「画像を翻訳」を選択するだけで、翻訳後の画像をすぐに取得できます。

⌨️

キーボードショートカット

Ctrl+Shift+F を押すと、カーソル下の画像を翻訳できます。素早く効率的です。

🔄

自動翻訳

自動翻訳を有効にすると、ページの読み込み時に画像が自動的に翻訳されます。長編マンガの閲覧に最適です。

📸

スクリーンショット翻訳

ブラウザ上で画面の一部をキャプチャして翻訳できます。ダウンロードできない画像の翻訳や、画像の一部の領域だけを翻訳したい場合に適しています。

🤖

柔軟な翻訳オプション

任意の OCR バックエンド（ImageTrans または PaddleOCR）と、OpenAI 互換 API（ChatGPT、Gemini、DeepSeek）または内蔵の翻訳エンジンを組み合わせて、最適な翻訳結果を得られます。

🀄

ルビ・ピンインの表示

日本語の文字に仮名を、中国語の文字にピンインを付加できます——語学学習者の強力な味方です。

使い方

  1. 拡張機能をインストール Chrome ウェブストア、Firefox アドオン、または Microsoft Edge アドオンストア から追加します。 📱 モバイル： iOS では Orion ブラウザを使うことで Chrome または Firefox の拡張機能を利用できます。Android では Firefox for Android、Edge、Kiwi ブラウザを利用できます。
  2. バックエンドを設定 ImageTrans サーバーに接続するか、内蔵の PaddleOCR を使用するか、ご自身の OpenAI 互換 API キーを設定します。
  3. 翻訳を開始 画像を右クリック →「画像を翻訳」。自動翻訳を有効にすれば、ページの読み込み時にすべての画像を自動翻訳できます。スクリーンショット機能で画面の一部を翻訳したり、撮影機能で撮影してリアルタイムに翻訳することもできます。これで完了です！

仕組み

🔌 ImageTrans デスクトップ版と連携（推奨）

  • ImageTrans が検出 → OCR → 文字消去 → 翻訳 → レンダリングという一連の流れを担当します
  • 最高の精度、最も幅広い言語サポート、豊富な編集機能
  • 拡張機能が画像を ImageTrans に送って処理し、完成した画像をそのまま表示します
  • ImageTrans がローカルまたはサーバー上で動作している必要があります

🧩 ImageTrans に依存しない（ブラウザのみで動作）

  • 拡張機能がフロントエンドですべての処理を完結します：OCR（PaddleOCR）→ 翻訳 → レンダリング
  • サーバーやソフトウェアのインストールは不要——完全に自己完結
  • 無料で、プライバシーも保護されます
  • 精度、速度、言語の選択肢はやや限定的です

翻訳オプション

以下の翻訳方法はどちらのモードでも利用できます。ImageTrans と組み合わせて OpenAI 互換 API を使用する場合、ImageTrans は OCR のみを担当し、翻訳とレンダリングは拡張機能がフロントエンドで行います。

🌐 ImageTrans 内蔵翻訳

  • ImageTrans に接続しているときに利用できます
  • 多様な翻訳エンジンに対応（Google、DeepL、Baidu など）
  • 翻訳メモリ、用語管理、コーパス検索の機能を搭載

🤖 OpenAI 互換 API

  • ChatGPT、Gemini、DeepSeek、または任意の互換 API を利用
  • ImageTrans と組み合わせても、単独でも使用可能——ご自身の API キーを使用します
  • 柔軟なカスタムプロンプトで、より細やかな翻訳を実現
  • ImageTrans と併用する場合：ImageTrans は OCR のみを担当し、翻訳とレンダリングは拡張機能が行います

🆓 MyMemory（無料）

  • 無料の機械翻訳 API で、キーは不要です
  • 素早く一時的な翻訳ニーズに適しています

ImageTrans デスクトップ版について

ImageTrans は、機能が充実したコンピュータ支援の画像翻訳デスクトップソフトウェアです。ブラウザ拡張は素早いその場での翻訳に適していますが、ImageTrans デスクトップ版なら翻訳ワークフロー全体を完全にコントロールできます。

🎛️

強力なカスタマイズ機能

各ステップを細かく調整できます。複数の OCR エンジンから自由に選択し、検出アルゴリズムを設定し、レンダリングのパラメータをカスタマイズして、ニーズに正確に応えます。

✏️

手動編集

テキスト領域の調整、OCR 結果の修正、翻訳内容の編集、文字位置の微調整——自動化が十分でないときも、すべてを思いのままに操作できます。

🎨

PSD の書き出し

翻訳後の画像を Photoshop（PSD）ファイルとして書き出します。テキストがレイヤーごとに分かれているので、デザイナーに渡して後工程を進めるのが簡単です。

📦

バッチ処理

一度に数百枚の画像を翻訳します。Excel、Word、XLIFF によるデータのインポート・エクスポートに対応し、他の翻訳ツールともシームレスに連携できます。

どんなものを翻訳できますか？

📚

マンガとウェブトゥーン

あらゆるウェブサイトで、翻訳されたマンガ、ウェブトゥーン、同人作品を読むことができます。この拡張機能はマンガの吹き出しや文字レイアウトに合わせて最適化されています。

📋

ポスターとパンフレット

外国語の宣伝資料、インフォグラフィック、広告の内容をすばやく理解できます。

📱

スクリーンショットと写真

スクリーンショット機能で画像の一部の領域を翻訳したり、ウェブページ上でダウンロードできない画像を翻訳したりできます——すべてブラウザ内で完結します。

📝

画像から文字を抽出

翻訳せずに画像から文字を抽出できます。OCR タスク、データ入力、アクセシビリティの場面に適しています。
