إضافة المتصفح ImageTrans

ما هي إضافة المتصفح ImageTrans؟

إضافة المتصفح ImageTrans تجلب قدرات ترجمة الصور المدعومة بالذكاء الاصطناعي مباشرة إلى متصفحك. فهي تكتشف النص الموجود في الصور على صفحات الويب (القصص المصورة، الملصقات، لقطات الشاشة، الكتيبات، وغيرها) وتستبدله تلقائيًا بالنسخة المترجمة.

استنادًا إلى PaddleOCR والخلفية البرمجية لتطبيق سطح المكتب ImageTrans، تجمع الإضافة بين أحدث تقنيات التعرّف الضوئي على الحروف والترجمة الآلية العصبية لتقدم لك ترجمات دقيقة تراعي السياق.

الميزات الرئيسية

🖱️

الترجمة بالنقر الأيمن

انقر بزر الفأرة الأيمن على أي صورة في صفحة الويب، ثم اختر «ترجمة الصورة» للحصول على النسخة المترجمة فورًا.

⌨️

اختصار لوحة المفاتيح

اضغط Ctrl+Shift+F لترجمة الصورة الموجودة تحت المؤشر، بسرعة وكفاءة.

🔄

الترجمة التلقائية

عند تفعيل الترجمة التلقائية، تُترجم الصور تلقائيًا عند تحميل الصفحة. مثالي لقراءة القصص المصورة الطويلة.

📸

ترجمة لقطات الشاشة

التقط منطقة من الشاشة داخل المتصفح لترجمتها، وهو مناسب لترجمة الصور التي لا يمكن تنزيلها أو لترجمة جزء من الصورة فقط.

🤖

خيارات ترجمة مرنة

استخدم أي خلفية للتعرّف الضوئي على الحروف (ImageTrans أو PaddleOCR) مع واجهة API متوافقة مع OpenAI (ChatGPT وGemini وDeepSeek) أو مع محركات الترجمة المدمجة للحصول على أفضل نتائج الترجمة.

🀄

تعليقات النطق

أضف الفراغانا إلى النصوص اليابانية والبينيين إلى النصوص الصينية — مساعد قيّم لمتعلمي اللغات.

كيفية الاستخدام

  1. تثبيت الإضافة أضفها من متجر Chrome أو إضافات Firefox أو متجر إضافات Microsoft Edge. 📱 الأجهزة المحمولة: على iOS يمكنك استخدام متصفح Orion لتشغيل إضافات Chrome أو Firefox. وعلى Android يمكنك استخدام Firefox for Android أو Edge أو متصفح Kiwi.
  2. إعداد الخلفية البرمجية اتصل بخادم ImageTrans، أو استخدم PaddleOCR المدمج، أو اضبط مفتاح API خاصًا بك متوافقًا مع OpenAI.
  3. ابدأ الترجمة انقر بزر الفأرة الأيمن على الصورة → «ترجمة الصورة». يمكنك أيضًا تفعيل الترجمة التلقائية لترجمة جميع الصور عند تحميل الصفحة، أو استخدام خاصية لقطة الشاشة لترجمة جزء من الشاشة، أو خاصية التصوير لالتقاط صورة وترجمتها فورًا. انتهيت!

كيف تعمل

🔌 مع ImageTrans لسطح المكتب (موصى به)

  • يتولى ImageTrans العملية كاملة: الكشف → التعرّف الضوئي على الحروف → محو النص → الترجمة → العرض
  • أفضل دقة وأوسع دعم للغات وميزات تحرير غنية
  • ترسل الإضافة الصور إلى ImageTrans لمعالجتها ثم تعرض النتيجة النهائية مباشرة
  • يتطلب تشغيل ImageTrans محليًا أو على خادم

🧩 دون الاعتماد على ImageTrans (يعمل بالكامل في المتصفح)

  • تنفذ الإضافة العملية كاملة في الواجهة الأمامية: التعرّف الضوئي على الحروف (PaddleOCR) → الترجمة → العرض
  • لا حاجة إلى خادم أو تثبيت أي برنامج — مكتفية ذاتيًا بالكامل
  • مجانية وتحافظ على الخصوصية
  • دقة وسرعة وخيارات لغات أكثر محدودية

خيارات الترجمة

تتوفر طرق الترجمة التالية في الوضعين كليهما. وعند استخدام واجهة API متوافقة مع OpenAI مع ImageTrans، يتولى ImageTrans التعرّف الضوئي على الحروف فقط، بينما تنفذ الإضافة الترجمة والعرض في الواجهة الأمامية.

🌐 الترجمة المدمجة في ImageTrans

  • متاحة عند الاتصال بـ ImageTrans
  • تدعم محركات ترجمة متعددة (Google وDeepL وBaidu وغيرها)
  • تتضمن ذاكرة الترجمة وإدارة المصطلحات والبحث في المدونات اللغوية

🤖 واجهة API متوافقة مع OpenAI

  • استخدم ChatGPT أو Gemini أو DeepSeek أو أي واجهة API متوافقة
  • قابلة للاستخدام مع ImageTrans أو بدونه — بمفتاح API الخاص بك
  • أوامر توجيهية مخصصة ومرنة لترجمة أكثر دقة
  • مع ImageTrans: يتولى ImageTrans التعرّف الضوئي على الحروف فقط، وتتولى الإضافة الترجمة والعرض

🆓 MyMemory (مجاني)

  • واجهة ترجمة آلية مجانية، دون مفتاح
  • مناسبة لاحتياجات الترجمة السريعة والعابرة

حول ImageTrans لسطح المكتب

ImageTrans برنامج سطح مكتب متكامل لترجمة الصور بمساعدة الحاسوب. إضافة المتصفح مناسبة للترجمة السريعة الفورية، بينما يمنحك ImageTrans لسطح المكتب تحكمًا كاملًا في سير عمل الترجمة بأكمله.

🎛️

ميزات تخصيص قوية

اضبط كل خطوة بدقة: اختر بحرية من بين محركات تعرّف ضوئي متعددة، واضبط خوارزميات الكشف، وخصص معاملات العرض لتلبية احتياجاتك بدقة.

✏️

التحرير اليدوي

عدّل مناطق النص، وصحّح نتائج التعرّف الضوئي، وحرّر الترجمات، واضبط مواضع النص — عندما لا يكفي التشغيل الآلي، تبقى كل الأمور تحت سيطرتك.

🎨

تصدير PSD

صدّر الصور المترجمة إلى ملفات Photoshop (PSD) مع طبقات نصية مستقلة، لتسهيل تسليمها إلى المصممين للمعالجة اللاحقة.

📦

المعالجة بالدفعات

ترجم مئات الصور دفعة واحدة. يدعم استيراد البيانات وتصديرها عبر Excel أو Word أو XLIFF للتكامل السلس مع أدوات الترجمة الأخرى.
