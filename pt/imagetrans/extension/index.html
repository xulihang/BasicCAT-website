Extensão de navegador ImageTrans

Traduza qualquer imagem em uma página da web com um clique, com design voltado para quadrinhos, pôsteres, capturas de tela e outros cenários. Clique com o botão direito ou use o atalho de teclado para obter o resultado da tradução.

O que é a extensão de navegador ImageTrans?

A extensão de navegador ImageTrans leva o poder da tradução de imagens com IA diretamente para o seu navegador. Ela detecta o texto presente nas imagens de uma página da web (quadrinhos, pôsteres, capturas de tela, folhetos etc.) e o substitui automaticamente pela versão traduzida.

Com base no PaddleOCR e no backend do aplicativo de desktop ImageTrans, a extensão combina tecnologia de OCR de ponta com tradução automática neural para oferecer resultados precisos e adequados ao contexto.

Principais recursos

🖱️

Tradução com o botão direito

Clique com o botão direito em qualquer imagem de uma página da web e selecione “Traduzir imagem” para obter na hora a versão traduzida.

⌨️

Atalhos de teclado

Pressione Ctrl+Shift+F para traduzir a imagem sob o cursor, de forma rápida e eficiente.

🔄

Tradução automática

Com a tradução automática ativada, as imagens são traduzidas automaticamente quando a página é carregada. Ideal para ler quadrinhos longos.

📸

Tradução de capturas de tela

Capture uma área da tela no navegador para traduzi-la. É ideal para traduzir imagens que não podem ser baixadas ou apenas uma parte específica da imagem.

🤖

Opções de tradução flexíveis

Combine qualquer backend de OCR (ImageTrans ou PaddleOCR) com APIs compatíveis com OpenAI (ChatGPT, Gemini, DeepSeek) ou com os mecanismos de tradução integrados para obter os melhores resultados.

🀄

Anotações de pronúncia

Adicione kana ao texto em japonês e pinyin ao texto em chinês — um grande aliado para quem estuda idiomas.

Como usar

  1. Instale a extensão Adicione-a pela Chrome Web Store, pelos complementos do Firefox ou pela loja de complementos do Microsoft Edge. 📱 Dispositivos móveis: no iOS, você pode usar o navegador Orion para rodar extensões do Chrome ou do Firefox. No Android, pode usar o Firefox for Android, o Edge ou o navegador Kiwi.
  2. Configure o backend Conecte-se a um servidor ImageTrans, use o PaddleOCR integrado ou configure sua própria chave de API compatível com OpenAI.
  3. Comece a traduzir Clique com o botão direito na imagem → “Traduzir imagem”. Você também pode ativar a tradução automática para traduzir todas as imagens quando a página carregar; usar o recurso de captura de tela para traduzir parte da tela; ou usar o recurso de câmera para fotografar e traduzir em tempo real. Pronto!

Como funciona

🔌 Com o ImageTrans para desktop (recomendado)

  • O ImageTrans cuida de todo o fluxo: detecção → OCR → remoção do texto → tradução → renderização
  • Melhor precisão, o suporte mais amplo a idiomas e recursos avançados de edição
  • A extensão envia a imagem ao ImageTrans para processamento e exibe o resultado pronto na hora
  • Requer o ImageTrans em execução localmente ou em um servidor

🧩 Sem depender do ImageTrans (execução apenas no navegador)

  • A extensão realiza todo o processo de forma independente no front-end: OCR (PaddleOCR) → tradução → renderização
  • Não exige servidor nem instalação de qualquer software — totalmente autossuficiente
  • Gratuita e com privacidade preservada
  • Precisão, velocidade e opções de idiomas mais limitadas

Opções de tradução

Os métodos de tradução a seguir funcionam nos dois modos. Ao usar uma API compatível com OpenAI junto com o ImageTrans, o ImageTrans é responsável apenas pelo OCR, enquanto a tradução e a renderização são feitas pela extensão no front-end.

🌐 Tradução integrada do ImageTrans

  • Disponível quando há conexão com o ImageTrans
  • Suporta diversos mecanismos de tradução (Google, DeepL, Baidu etc.)
  • Inclui memória de tradução, gerenciamento de terminologia e busca em corpus

🤖 API compatível com OpenAI

  • Use o ChatGPT, o Gemini, o DeepSeek ou qualquer API compatível
  • Funciona com ou sem o ImageTrans — use a sua própria chave de API
  • Prompts personalizados e flexíveis para uma tradução mais refinada
  • Com o ImageTrans: o ImageTrans faz apenas o OCR, e a extensão cuida da tradução e da renderização

🆓 MyMemory (gratuito)

  • API de tradução automática gratuita, sem necessidade de chave
  • Ideal para necessidades de tradução rápidas e pontuais

Sobre o ImageTrans para desktop

O ImageTrans é um software de desktop completo de tradução de imagens assistida por computador. A extensão de navegador é ideal para traduções rápidas e imediatas, enquanto o ImageTrans para desktop dá a você controle total sobre todo o fluxo de trabalho de tradução.

🎛️

Personalização poderosa

Ajuste cada etapa com precisão: escolha livremente entre diversos motores de OCR, configure algoritmos de detecção e personalize parâmetros de renderização para atender exatamente às suas necessidades.

✏️

Edição manual

Ajuste áreas de texto, corrija resultados de OCR, edite o conteúdo traduzido e refine a posição do texto — quando a automação não for suficiente, você tem tudo sob controle.

🎨

Exportação para PSD

Exporte as imagens traduzidas como arquivos do Photoshop (PSD), com o texto em camadas separadas, o que facilita o trabalho posterior de um designer.

📦

Processamento em lote

Traduza centenas de imagens de uma só vez. Suporta importação e exportação de dados via Excel, Word ou XLIFF, integrando-se perfeitamente a outras ferramentas de tradução.
