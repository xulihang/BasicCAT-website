Você pode ajudar a melhorar o ImageTrans das seguintes formas:

1. Traduzir a documentação

	A documentação do ImageTrans é feita com o Sphinx e hospedada no readthedocs.

	Repositório da documentação: <https://github.com/xulihang/ImageTrans-docs>

	É preciso usar a ferramenta de localização do Sphinx para extrair os arquivos po e traduzi-los.

2. Traduzir a interface do software

	O ImageTrans usa o [B4XLocalizator](https://www.b4x.com/android/forum/threads/b4x-localizator-localize-your-b4x-applications.68751/) para fazer a localização, e é preciso traduzir o arquivo strings.xlsx. Depois de traduzido, ele deve ser convertido em strings.db para que o software o utilize.
	
	Baixe o strings.xlsx aqui: <https://github.com/xulihang/ImageTrans_l10n_en/releases/tag/strings>

3. Desenvolver plugins

	O ImageTrans usa o ABPlugin para desenvolver plugins. Código dos plugins existentes: <https://github.com/xulihang/ImageTrans_plugins>
	
4. Enviar sugestões

	Acesse a [página de issues](https://github.com/xulihang/ImageTrans-docs/issues) da documentação para enviar sugestões.
