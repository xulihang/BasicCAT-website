Sie können auf folgende Weise dazu beitragen, ImageTrans zu verbessern:

1. Dokumentation übersetzen

	Die Dokumentation von ImageTrans wird mit Sphinx erstellt und auf readthedocs gehostet.

	Repository der Dokumentation: <https://github.com/xulihang/ImageTrans-docs>

	Sie müssen das Lokalisierungswerkzeug von Sphinx verwenden, um die po-Dateien zu extrahieren und zu übersetzen.

2. Benutzeroberfläche der Software übersetzen

	ImageTrans verwendet [B4XLocalizator](https://www.b4x.com/android/forum/threads/b4x-localizator-localize-your-b4x-applications.68751/) für die Lokalisierung; dazu muss die Datei strings.xlsx übersetzt werden. Nach Abschluss der Übersetzung wird sie in strings.db umgewandelt, damit die Software sie verwenden kann.
	
	strings.xlsx können Sie hier herunterladen: <https://github.com/xulihang/ImageTrans_l10n_en/releases/tag/strings>

3. Plugins entwickeln

	ImageTrans verwendet ABPlugin zur Entwicklung von Plugins. Code der vorhandenen Plugins: <https://github.com/xulihang/ImageTrans_plugins>
	
4. Vorschläge einreichen

	Besuchen Sie die [Issue-Seite](https://github.com/xulihang/ImageTrans-docs/issues) der Dokumentation, um Vorschläge einzureichen.
