ImageTrans Browser-Erweiterung

Übersetzen Sie jedes Bild auf einer Webseite mit einem Klick – entwickelt für Comics, Poster, Screenshots und ähnliche Szenarien. Ein Rechtsklick oder eine Tastenkombination genügt, um sofort das Übersetzungsergebnis zu erhalten.

Kostenlos und Open Source (GPL v2.0)
🌐 Zu Chrome hinzufügen 🦊 Zu Firefox hinzufügen 🧊 Zu Edge hinzufügen

Was ist die ImageTrans Browser-Erweiterung?

Die ImageTrans Browser-Erweiterung bringt KI-gestützte Bildübersetzung direkt in Ihren Browser. Sie erkennt Text in Bildern auf Webseiten (Comics, Poster, Screenshots, Broschüren usw.) und ersetzt ihn automatisch durch die übersetzte Version.

Auf Basis von PaddleOCR und dem Backend der ImageTrans-Desktop-Anwendung kombiniert die Erweiterung modernste OCR-Technologie mit neuronaler maschineller Übersetzung und liefert Ihnen präzise, kontextgerechte Übersetzungsergebnisse.

Hauptfunktionen

🖱️

Übersetzen per Rechtsklick

Klicken Sie mit der rechten Maustaste auf ein beliebiges Bild auf einer Webseite und wählen Sie „Bild übersetzen“, um sofort die übersetzte Version zu erhalten.

⌨️

Tastaturkürzel

Drücken Sie Ctrl+Shift+F, um das Bild unter dem Cursor zu übersetzen – schnell und effizient.

🔄

Automatische Übersetzung

Wenn Sie die automatische Übersetzung aktivieren, werden Bilder beim Laden der Seite automatisch übersetzt. Ideal zum Lesen langer Comics.

📸

Screenshot-Übersetzung

Erfassen Sie im Browser einen Bildschirmbereich zur Übersetzung – geeignet für Bilder, die sich nicht herunterladen lassen, oder um nur einen Teil eines Bildes zu übersetzen.

🤖

Flexible Übersetzungsoptionen

Kombinieren Sie ein beliebiges OCR-Backend (ImageTrans oder PaddleOCR) mit einer OpenAI-kompatiblen API (ChatGPT, Gemini, DeepSeek) oder den integrierten Übersetzungsengines für die besten Ergebnisse.

🀄

Aussprache-Annotationen

Fügen Sie japanischem Text Furigana und chinesischem Text Pinyin hinzu – ein unentbehrlicher Helfer für Sprachlernende.

So verwenden Sie die Erweiterung

  1. Erweiterung installieren Fügen Sie sie über den Chrome Web Store, die Firefox-Add-ons oder den Microsoft-Edge-Add-on-Store hinzu. 📱 Mobilgeräte: Unter iOS können Sie Chrome- oder Firefox-Erweiterungen mit dem Browser Orion ausführen. Unter Android können Sie Firefox für Android, Edge oder den Browser Kiwi verwenden.
  2. Backend konfigurieren Stellen Sie eine Verbindung zu einem ImageTrans-Server her, verwenden Sie das integrierte PaddleOCR oder konfigurieren Sie Ihren eigenen OpenAI-kompatiblen API-Schlüssel.
  3. Mit dem Übersetzen beginnen Rechtsklick auf ein Bild → „Bild übersetzen“. Sie können auch die automatische Übersetzung aktivieren, um beim Laden der Seite alle Bilder automatisch zu übersetzen; die Screenshot-Funktion nutzen, um einen Teil des Bildschirms zu übersetzen; oder die Kamera-Funktion verwenden, um ein Foto zu machen und in Echtzeit zu übersetzen. Fertig!

So funktioniert es

🔌 Mit ImageTrans Desktop (empfohlen)

  • ImageTrans übernimmt den gesamten Ablauf: Erkennung → OCR → Textentfernung → Übersetzung → Rendering
  • Beste Genauigkeit, größte Sprachvielfalt und umfangreiche Bearbeitungsfunktionen
  • Die Erweiterung sendet das Bild an ImageTrans und zeigt direkt das fertige Ergebnis an
  • Erfordert, dass ImageTrans lokal oder auf einem Server läuft

🧩 Ohne ImageTrans (rein im Browser)

  • Die Erweiterung führt den gesamten Ablauf eigenständig im Frontend aus: OCR (PaddleOCR) → Übersetzung → Rendering
  • Kein Server und keine Softwareinstallation nötig – vollständig eigenständig
  • Kostenlos und datenschutzfreundlich
  • Geringere Genauigkeit, Geschwindigkeit und Sprachauswahl

Übersetzungsoptionen

Die folgenden Übersetzungsmethoden sind in beiden Modi verfügbar. Bei Verwendung einer OpenAI-kompatiblen API mit ImageTrans übernimmt ImageTrans nur die OCR; Übersetzung und Rendering erfolgen durch die Erweiterung im Frontend.

🌐 Integrierte Übersetzung von ImageTrans

  • Verfügbar bei Verbindung mit ImageTrans
  • Unterstützt mehrere Übersetzungsengines (Google, DeepL, Baidu usw.)
  • Enthält Translation Memory, Terminologieverwaltung und Korpusrecherche

🤖 OpenAI-kompatible API

  • Verwenden Sie ChatGPT, Gemini, DeepSeek oder eine beliebige kompatible API
  • Funktioniert mit und ohne ImageTrans – mit Ihrem eigenen API-Schlüssel
  • Flexible benutzerdefinierte Prompts für eine feinere Übersetzung
  • Mit ImageTrans: ImageTrans übernimmt nur die OCR, die Erweiterung übernimmt Übersetzung und Rendering

🆓 MyMemory (kostenlos)

  • Kostenlose maschinelle Übersetzungs-API, kein Schlüssel erforderlich
  • Geeignet für schnelle, gelegentliche Übersetzungen

Über ImageTrans Desktop

ImageTrans ist eine voll ausgestattete Desktop-Software für computergestützte Bildübersetzung. Die Browser-Erweiterung eignet sich für schnelle, sofortige Übersetzungen, während Sie mit ImageTrans Desktop den gesamten Übersetzungsworkflow vollständig steuern.

🎛️

Umfangreiche Anpassungsmöglichkeiten

Feinabstimmung jedes Schritts: Wählen Sie aus mehreren OCR-Engines, konfigurieren Sie Erkennungsalgorithmen und passen Sie Rendering-Parameter an, um Ihre Anforderungen genau zu erfüllen.

✏️

Manuelle Bearbeitung

Textbereiche anpassen, OCR-Ergebnisse korrigieren, Übersetzungen bearbeiten, Textpositionen feinjustieren – wenn die Automatisierung nicht ausreicht, behalten Sie die volle Kontrolle.

🎨

PSD-Export

Exportieren Sie übersetzte Bilder als Photoshop-(PSD-)Dateien mit Texten auf separaten Ebenen, damit Designer sie einfach nachbearbeiten können.

📦

Stapelverarbeitung

Übersetzen Sie Hunderte von Bildern auf einmal. Unterstützt den Import und Export von Daten über Excel, Word oder XLIFF für eine nahtlose Anbindung an andere Übersetzungswerkzeuge.

Was können Sie übersetzen?

📚

Comics und Webtoons

Lesen Sie übersetzte Comics, Webtoons und Fan-Werke auf jeder Website. Die Erweiterung ist für Comic-Sprechblasen und die Textanordnung optimiert.

📋

Poster und Broschüren

Erfassen Sie fremdsprachige Werbematerialien, Infografiken und Anzeigen schnell.

📱

Screenshots und Fotos

Verwenden Sie die Screenshot-Funktion, um einen Teil eines Bildes zu übersetzen, oder übersetzen Sie Bilder, die sich von einer Webseite nicht herunterladen lassen – alles direkt im Browser.

📝

Text aus Bildern extrahieren

Extrahieren Sie Text aus Bildern, ohne ihn zu übersetzen. Geeignet für OCR-Aufgaben, Dateneingabe und Barrierefreiheit.
