เกี่ยวกับเครื่องมือแปลภาพออนไลน์

เครื่องมือแปลภาพออนไลน์เป็นเครื่องมือเว็บโอเพนซอร์สฟรีที่แปลข้อความในภาพได้โดยตรงในเบราว์เซอร์: มังงะ ภาพหน้าจอ ภาพถ่าย และอื่น ๆ อีกมากมาย ไม่ต้องติดตั้ง

วิธีการทำงาน

โหมด PaddleOCR ภายในเครื่อง:OCR ทำงานทั้งหมดในเบราว์เซอร์ (PaddleOCR ที่คอมไพล์เป็น WebAssembly) และการแปลใช้ API MyMemory ฟรี หรือ API ที่เข้ากันได้กับ OpenAI (ChatGPT, DeepSeek ฯลฯ) โดยไม่ต้องใช้เซิร์ฟเวอร์

โหมดเซิร์ฟเวอร์ ImageTrans:เชื่อมต่อกับเซิร์ฟเวอร์ ImageTrans (สาธารณะหรือส่วนตัว) และดำเนินการรู้จำ OCR การแปล และการเรนเดอร์ข้อความในขั้นตอนเดียว

ImageTrans สำหรับเดสก์ท็อป

ต้องการติดตั้งบริการแปลภายในองค์กร แปลภาพจำนวนมาก หรือแก้ไขผลลัพธ์ด้วยตนเองใช่หรือไม่? ImageTrans สำหรับเดสก์ท็อปเป็นซอฟต์แวร์แปลภาพที่สมบูรณ์พร้อมระบบช่วยเหลือด้วยคอมพิวเตอร์ มีตัวแก้ไขภาพในตัว และรองรับเครื่องมือ OCR และบริการแปลหลากหลาย
