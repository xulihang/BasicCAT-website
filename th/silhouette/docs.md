## ระบบปฏิบัติการที่รองรับ

* Windows 7+
* macOS 10.15+
* Linux

## ติดตั้ง

สำหรับ Windows ให้แตกไฟล์แล้วเรียกใช้โปรแกรมด้วย `Silhouette.exe`

สำหรับ macOS ให้ลากแอปในไฟล์ dmg ไปยังโฟลเดอร์ `Applications` เพื่อติดตั้ง หากแสดงว่าแพ็กเกจเสียหาย ให้เปิดเทอร์มินัลแล้วรันคำสั่งต่อไปนี้:

```bash
sudo xattr -rd com.apple.quarantine /Applications/Silhouette.app
```

สำหรับ Linux สามารถใช้ไฟล์จากแพ็กเกจ zip ของ Windows ได้ จำเป็นต้องติดตั้ง FFmpeg, Whisper.cpp, Java และ JavaFX เพื่อรันโปรแกรม สามารถใช้[ไฟล์เทมเพลต](https://github.com/xulihang/Silhouette/releases/download/v1.1.0/Silhouette-Linux-template.zip)ที่มี dependency เหล่านี้อยู่ จากนั้นยังต้องดาวน์โหลด ONNXRuntime และแตกไฟล์ so ไปยังไดเรกทอรีของซอฟต์แวร์: [linux-onnxruntime-1.20.0.zip](https://github.com/xulihang/onnxruntime-for-win7/releases/download/builds/linux-onnxruntime-1.20.0.zip)

## การตั้งค่า

เมื่อเปิดโปรแกรม จำเป็นต้องป้อนหมายเลขคำสั่งซื้อและอีเมลเพื่อยืนยันการซื้อ สามารถใช้ช่วงทดลองใช้ 7 วันหรือโหมดจำกัดเพื่อทดลองใช้โปรแกรมก่อนได้

นอกจากนี้ ยังต้องตั้งค่าอื่น ๆ ให้เสร็จสมบูรณ์


1. โมเดล Whisper จำเป็นต้องเลือกโมเดล Whisper สำหรับการรู้จำเสียงพูด สามารถดูลิงก์ดาวน์โหลดได้ในโปรแกรมหรือ[ที่นี่](https://github.com/xulihang/Silhouette_plugins/#whisper-models)
2. คีย์ API หากต้องการใช้บริการแปล เช่น ChatGPT, Google หรือ DeepL จำเป็นต้องกรอกคีย์ API ในการตั้งค่า


## เริ่มต้นอย่างรวดเร็ว

ภาพหน้าจอของ Silhouette:

![ภาพหน้าจอ](/album/silhouette/screenshot_zh.webp){: width="1500" height="1160"}

ที่มุมซ้ายบน มีเครื่องเล่นวิดีโอพร้อมตัวควบคุมต่าง ๆ

ที่มุมซ้ายล่าง มีตารางแสดงบรรทัดซับไตเติลที่มีอยู่

ที่มุมขวาบน สามารถดูรูปคลื่นเสียงที่สอดคล้องกับบรรทัดซับไตเติลปัจจุบัน และแก้ไขการประทับเวลาและข้อความ

ที่มุมขวาล่าง สามารถดูผลลัพธ์จากบริการแปลหลาย ๆ แบบ

ต่อไปนี้คือขั้นตอนพื้นฐานในการแปลไฟล์วิดีโอ/เสียงด้วย Silhouette:

1. ใช้เมนูไฟล์ในแถบเมนูเพื่อเปิดไฟล์สื่อและกำหนดคู่ภาษา
2. ใช้เมนูแก้ไขเพื่อรู้จำเสียงพูด ตรวจจับเสียงพูด และแก้ไขบรรทัดซับไตเติล
3. หลังการถอดเสียงและการแปล สามารถส่งออกผลลัพธ์เป็นไฟล์ SRT หรือไฟล์ txt ที่คั่นด้วยแท็บ สามารถนำเข้าข้อมูลจากไฟล์เหล่านี้ได้เช่นกัน
