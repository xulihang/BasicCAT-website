ส่วนขยายเบราว์เซอร์ ImageTrans

แปลรูปภาพใดก็ได้บนเว็บเพจในคลิกเดียว ออกแบบมาสำหรับมังงะ โปสเตอร์ ภาพหน้าจอ และอื่น ๆ คลิกขวาหรือใช้ปุ่มลัดเพื่อรับผลการแปลทันที

ฟรีและโอเพนซอร์ส (GPL v2.0)
🌐 เพิ่มใน Chrome 🦊 เพิ่มใน Firefox 🧊 เพิ่มใน Edge

ส่วนขยายเบราว์เซอร์ ImageTrans คืออะไร?

ส่วนขยายเบราว์เซอร์ ImageTransนำความสามารถในการแปลรูปภาพที่ขับเคลื่อนด้วย AI มาสู่เบราว์เซอร์ของคุณโดยตรง สามารถตรวจจับข้อความบนรูปภาพในเว็บเพจ (มังงะ โปสเตอร์ ภาพหน้าจอ โบรชัวร์ ฯลฯ) และแทนที่ด้วยฉบับแปลอัตโนมัติ

อาศัย PaddleOCR และแบ็กเอนด์ของแอปเดสก์ท็อป ImageTrans ส่วนขยายผสานเทคโนโลยี OCR ที่ล้ำสมัยเข้ากับการแปลด้วยเครื่องแบบโครงข่ายประสาท เพื่อให้ผลลัพธ์ที่แม่นยำและสอดคล้องกับบริบท

ฟังก์ชันหลัก

🖱️

แปลด้วยคลิกขวา

คลิกขวาที่รูปภาพใดก็ได้บนเว็บเพจ เลือก "แปลรูปภาพ" เพื่อรับฉบับแปลทันที

⌨️

ปุ่มลัดบนคีย์บอร์ด

กด Ctrl+Shift+F เพื่อแปลรูปภาพใต้เคอร์เซอร์ รวดเร็วและมีประสิทธิภาพ

🔄

การแปลอัตโนมัติ

เมื่อเปิดใช้การแปลอัตโนมัติ รูปภาพจะถูกแปลเมื่อโหลดหน้า เหมาะมากสำหรับอ่านมังงะยาว ๆ

📸

การแปลภาพหน้าจอ

จับภาพพื้นที่บนหน้าจอในเบราว์เซอร์เพื่อแปล เหมาะสำหรับแปลรูปภาพที่ไม่สามารถดาวน์โหลดได้ หรือแปลเฉพาะบางส่วนของรูปภาพ

🤖

ตัวเลือกการแปลที่ยืดหยุ่น

จับคู่แบ็กเอนด์ OCR ใดก็ได้ (ImageTrans หรือ PaddleOCR) กับ API ที่เข้ากันได้กับ OpenAI (ChatGPT, Gemini, DeepSeek) หรือเอนจินแปลในตัว เพื่อผลการแปลที่ดีที่สุด

🀄

คำอ่านกำกับ

กำกับคานะให้ข้อความญี่ปุ่น กำกับพินอินให้ข้อความจีน — ผู้ช่วยชั้นดีสำหรับผู้เรียนภาษา

วิธีใช้งาน

  1. ติดตั้งส่วนขยาย เพิ่มจาก Chrome เว็บสโตร์, ส่วนเสริม Firefox หรือ ร้านส่วนเสริม Microsoft Edge 📱 มือถือ: บน iOS สามารถใช้เบราว์เซอร์ Orion รันปลั๊กอิน Chrome หรือ Firefox บน Android สามารถใช้ Firefox for Android, Edge หรือเบราว์เซอร์ Kiwi
  2. ตั้งค่าแบ็กเอนด์ เชื่อมต่อกับเซิร์ฟเวอร์ ImageTrans ใช้ PaddleOCR ในตัว หรือตั้งค่าคีย์ API ที่เข้ากันได้กับ OpenAI ของคุณเอง
  3. เริ่มแปล คลิกขวาที่รูปภาพ → "แปลรูปภาพ" คุณยังสามารถเปิดการแปลอัตโนมัติเพื่อแปลรูปภาพทั้งหมดเมื่อโหลดหน้า ใช้ฟังก์ชันจับภาพหน้าจอเพื่อแปลบางส่วนของหน้าจอ หรือใช้ฟังก์ชันถ่ายภาพเพื่อถ่ายและแปลแบบเรียลไทม์ เสร็จแล้ว!

วิธีการทำงาน

🔌 ใช้กับ ImageTrans เดสก์ท็อป (แนะนำ)

  • ImageTrans รับผิดชอบกระบวนการทั้งหมด: ตรวจจับ → OCR → ลบข้อความ → แปล → เรนเดอร์
  • ความแม่นยำสูงสุด รองรับภาษากว้างที่สุด และฟังก์ชันแก้ไขหลากหลาย
  • ส่วนขยายส่งรูปภาพให้ ImageTrans ประมวลผลแล้วแสดงผลสำเร็จรูปโดยตรง
  • ต้องมี ImageTrans ทำงานบนเครื่องโลคอลหรือเซิร์ฟเวอร์

🧩 ไม่พึ่ง ImageTrans (ทำงานในเบราว์เซอร์ล้วน)

  • ส่วนขยายทำกระบวนการทั้งหมดด้วยตัวเองบนฟรอนต์เอนด์: OCR (PaddleOCR) → แปล → เรนเดอร์
  • ไม่ต้องใช้เซิร์ฟเวอร์หรือติดตั้งซอฟต์แวร์ใด ๆ — ครบในตัวเอง
  • ฟรีและปกป้องความเป็นส่วนตัว
  • ความแม่นยำ ความเร็ว และตัวเลือกภาษาค่อนข้างจำกัด

ตัวเลือกการแปล

วิธีการแปลต่อไปนี้ใช้ได้ทั้งสองโหมด เมื่อใช้ API ที่เข้ากันได้กับ OpenAI ร่วมกับ ImageTrans, ImageTrans จะรับผิดชอบเฉพาะ OCR ส่วนการแปลและการเรนเดอร์ทำโดยส่วนขยายบนฟรอนต์เอนด์

🌐 การแปลในตัวของ ImageTrans

  • ใช้ได้เมื่อเชื่อมต่อกับ ImageTrans
  • รองรับเอนจินแปลหลายแบบ (Google, DeepL, Baidu ฯลฯ)
  • มีหน่วยความจำการแปล การจัดการศัพท์ และการค้นหาคลังข้อความ

🤖 API ที่เข้ากันได้กับ OpenAI

  • ใช้ ChatGPT, Gemini, DeepSeek หรือ API ที่เข้ากันได้ใดก็ได้
  • ใช้ได้ทั้งกับและไม่กับ ImageTrans — ใช้คีย์ API ของคุณเอง
  • พรอมต์กำหนดเองที่ยืดหยุ่น เพื่อการแปลที่ละเอียดยิ่งขึ้น
  • เมื่อใช้กับ ImageTrans: ImageTrans ทำเฉพาะ OCR ส่วนขยายทำการแปลและเรนเดอร์

🆓 MyMemory (ฟรี)

  • API แปลด้วยเครื่องฟรี ไม่ต้องใช้คีย์
  • เหมาะสำหรับความต้องการแปลเร็วและชั่วคราว

เกี่ยวกับ ImageTrans เดสก์ท็อป

ImageTrans เป็นซอฟต์แวร์เดสก์ท็อปแปลรูปภาพด้วยคอมพิวเตอร์ช่วยที่ครบครัน ส่วนขยายเบราว์เซอร์เหมาะสำหรับการแปลเร็วทันใจ ส่วน ImageTrans เดสก์ท็อปให้คุณควบคุมขั้นตอนการทำงานแปลทั้งหมดได้อย่างเต็มที่

🎛️

ฟังก์ชันปรับแต่งที่ทรงพลัง

ปรับแต่งแต่ละขั้นตอนอย่างละเอียด: เลือกเอนจิน OCR ได้หลากหลาย ตั้งค่าอัลกอริทึมตรวจจับ ปรับพารามิเตอร์การเรนเดอร์ให้ตรงกับความต้องการของคุณอย่างแม่นยำ

✏️

การแก้ไขด้วยมือ

ปรับพื้นที่ข้อความ แก้ไขผล OCR แก้ไขเนื้อหาคำแปล ปรับตำแหน่งข้อความอย่างละเอียด — เมื่อระบบอัตโนมัติไม่พอ ทุกอย่างอยู่ในมือคุณ

🎨

ส่งออก PSD

ส่งออกรูปภาพที่แปลแล้วเป็นไฟล์ Photoshop (PSD) โดยแยกข้อความเป็นเลเยอร์อิสระ สะดวกในการส่งให้นักออกแบบปรับแต่งต่อ

📦

การประมวลผลแบบกลุ่ม

แปลรูปภาพหลายร้อยรูปในครั้งเดียว รองรับการนำเข้าและส่งออกข้อมูลผ่าน Excel, Word หรือ XLIFF เชื่อมต่อกับเครื่องมือแปลอื่นได้อย่างไร้รอยต่อ

💡 เรียนรู้เพิ่มเติมเกี่ยวกับ ImageTrans เดสก์ท็อป →

คุณแปลอะไรได้บ้าง?

📚

มังงะและเว็บตูน

อ่านมังงะ เว็บตูน และงานแฟนอาร์ตที่แปลแล้วบนเว็บไซต์ใดก็ได้ ส่วนขยายได้รับการปรับแต่งสำหรับบอลลูนคำพูดและการจัดวางข้อความในมังงะ

📋

โปสเตอร์และโบรชัวร์

เข้าใจสื่อโฆษณา อินโฟกราฟิก และเนื้อหาโฆษณาต่างประเทศได้อย่างรวดเร็ว

📱

ภาพหน้าจอและรูปถ่าย

ใช้ฟังก์ชันจับภาพหน้าจอเพื่อแปลบางส่วนของรูปภาพ หรือแปลรูปภาพที่ดาวน์โหลดจากเว็บเพจไม่ได้ — ทั้งหมดทำในเบราว์เซอร์

📝

ดึงข้อความจากรูปภาพ

ดึงข้อความจากรูปภาพโดยไม่ต้องแปล เหมาะสำหรับงาน OCR การป้อนข้อมูล และสถานการณ์ด้านการเข้าถึง
