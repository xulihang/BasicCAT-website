ImageTrans เป็นเครื่องมือถอดความและแปลข้อความในรูปภาพด้วยคอมพิวเตอร์ช่วย สามารถใช้เทคโนโลยี OCR ระบุตำแหน่งและรู้จำข้อความอัตโนมัติ ลบต้นฉบับและเติมคำแปลโดยอัตโนมัติ พร้อมด้วยอัลกอริทึมรวมและตรวจจับพื้นที่ข้อความที่ออกแบบมาสำหรับมังงะ

นอกจากใช้เป็นตัวแปลรูปภาพสำหรับแปลโปสเตอร์และมังงะแล้ว ImageTrans ยังใช้สำหรับการอ่านรูปภาพ การถอดความข้อความ การแปลภาพหน้าจอด้วย OCR การแปลง PDF เป็น markdown พร้อมแปล การสร้าง PDF สองชั้นที่ค้นหาได้จากเอกสารสแกน และการติดป้ายกำกับข้อมูลสำหรับการเรียนรู้เชิงลึก เป็นต้น

ImageTrans เป็นผลงานวิทยานิพนธ์ปริญญาโทของผม: การออกแบบและการพัฒนาของเครื่องมือช่วยแปลมังงะ

🔍

ระบุตำแหน่งพื้นที่ข้อความอย่างแม่นยำ

รองรับวิธีการหลากหลาย เช่น การตรวจจับข้อความในฉากธรรมชาติ การตรวจจับวัตถุ และวิธีแบบฮิวริสติก พร้อมอัลกอริทึมรวมและตรวจจับพื้นที่ข้อความที่ออกแบบสำหรับบอลลูนคำพูดในมังงะ

📖

การรู้จำ OCR หลายเอนจิน

รองรับเอนจิน OCR หลายแบบและปลั๊กอินกำหนดเอง ครอบคลุมภาษาหลักของโลก รองรับการรู้จำภาษาจีนและญี่ปุ่นแนวตั้ง โดยกำหนดลำดับการอ่านผ่านการวิเคราะห์เลย์เอาต์ และสามารถใช้โมเดลภาษาขนาดใหญ่ตรวจแก้เพื่อปรับปรุงความแม่นยำของ OCR

🌐

การแปล

การแปลด้วยเครื่อง: รองรับเอนจินแปลด้วยเครื่องหลายแบบและโมเดล AI ขนาดใหญ่ (ChatGPT, Gemini, DeepSeek ฯลฯ) ใช้ข้อมูลบริบทเพื่อยกระดับคุณภาพการแปล

ฟังก์ชันช่วยเหลือ: เปรียบเทียบผลลัพธ์หลายรายการเคียงข้างกัน หน่วยความจำการแปล การค้นหาคลังข้อความ การจัดการศัพท์ คำอ่านกำกับคานะและพินอิน และระบบค้นหาเสียงเลียนแบบในมังงะ

🧹

การลบข้อความ

รองรับอัลกอริทึมและโมเดล AI เช่น การทำไบนารี PatchMatch, Lama Inpaint, Gemini Nano Banana เพื่อสร้างมาสก์ข้อความและลบข้อความ คงลายจุดของมังงะไว้เมื่อลบข้อความ

🎨

การจัดวางข้อความ

  • ปรับขนาดฟอนต์อัตโนมัติ
  • ปรับการตัดบรรทัดสำหรับภาษาที่มีช่องว่างให้เหมาะสม (เช่น กรณีแปลญี่ปุ่นเป็นอังกฤษ)
  • การจัดการเครื่องหมายวรรคตอนที่ต้นหรือท้ายบรรทัด
  • ข้อความสมบูรณ์แบบและสไตล์ฟอนต์ (คล้ายระบบสไตล์ของ Word)
  • การตรวจจับสีข้อความ
  • การตรวจจับมุมการหมุน
  • การจัดวางข้อความแนวตั้ง
🖌️

ส่งออก PSD

บันทึกผลลัพธ์เป็นไฟล์ Photoshop PSD โดยแยกข้อความเป็นเลเยอร์อิสระ สะดวกให้นักออกแบบนำไปปรับแต่งต่อ

📦

การประมวลผลแบบกลุ่ม

ประมวลผลรูปภาพหลายร้อยรูปในครั้งเดียว รองรับขั้นตอนการทำงานกำหนดเอง การเรียกใช้จากบรรทัดคำสั่ง และการประมวลผลแบบขนานหลายโปรเซส เพื่อผลลัพธ์แบบกลุ่มความเร็วสูง

🖥️

อินเทอร์เฟซที่ใช้งานง่ายและทรงพลัง

ตัวแก้ไขแบบภาพพร้อมแสดงตัวอย่างแบบเรียลไทม์ ดำเนินการทีละขั้น เช่น OCR การแปล การตกแต่งภาพ การใส่ข้อความ ค้นหาและแทนที่ และขั้นตอนการทำงานกำหนดเอง — อินเทอร์เฟซเดียว ทรงพลังและใช้งานง่าย

ฟังก์ชันเพิ่มเติม

📄

การแปล PDF และการแปลงเป็น Markdown

แปล PDF และแปลงเป็น Markdown สามารถส่งออกต้นฉบับ คำแปล หรือฉบับสองภาษาคู่กัน โดยคงโครงสร้าง เช่น บทความหลายคอลัมน์ สูตร ตาราง และเชิงอรรถ สร้าง PDF สองชั้นที่ค้นหาได้

🖥️

การแปลหน้าจอแบบเรียลไทม์

จับภาพและแปลพื้นที่ใดก็ได้บนหน้าจอแบบเรียลไทม์ ตรวจจับการเปลี่ยนแปลงเนื้อหาอัตโนมัติ รองรับการจับคู่กับหน่วยความจำการแปลทันที

🎬

การดึงคำบรรยายฝังในวิดีโอ

ดึงคำบรรยายที่ฝังในวิดีโอ ด้วยการตรวจจับข้อความ OCR ที่รวดเร็ว ทั้งเร็วและแม่นยำ ส่งออกไฟล์คำบรรยาย SRT

📷

การสแกนและปรับปรุงเอกสาร

รองรับการสแกนแบบบูรณาการ TWAIN / WIA / SANE / ICA / eSCL ทำความสะอาด ปรับให้ตรง และปรับปรุงหนังสือที่สแกน เพื่อผลลัพธ์การประมวลผลภาพก่อนหน้าที่ดีที่สุด

ความง่ายในการใช้งาน

⌨️

ปุ่มลัดบนคีย์บอร์ด

เกือบทุกการดำเนินการรองรับปุ่มลัดบนคีย์บอร์ด ไม่ต้องสลับไปที่เมาส์บ่อย ๆ ขั้นตอนการทำงานรวดเร็วและมีประสิทธิภาพ

💻

การเรียกใช้จากบรรทัดคำสั่งและ API

รองรับการเรียกใช้ ImageTrans จากบรรทัดคำสั่งเพื่อทำงานอัตโนมัติ สามารถทำงานเป็นเซิร์ฟเวอร์ API ให้บริการแปลผ่าน HTTP สะดวกในการผสานรวมกับแอปหรือบริการใด ๆ

⚙️

ขั้นตอนการทำงานกำหนดเอง

ผสมผสานขั้นตอนการประมวลผล เช่น การตรวจจับ OCR การแปล และการเรนเดอร์ได้อย่างอิสระ เพื่อสร้างขั้นตอนการทำงานอัตโนมัติที่ตรงกับความต้องการของคุณ
