ImageTrans สำหรับ Android

แปลรูปภาพ ภาพถ่าย และข้อความบนหน้าจอได้โดยตรงบนมือถือ — แม้แต่ในเกม ImageTrans สำหรับ Android จะตรวจจับข้อความ แปล และวางคำแปลกลับในตำแหน่งเดิมบนรูปภาพโดยอัตโนมัติ — ไม่ต้องใช้คอมพิวเตอร์

🤖 Android 8+ 🆓 ฟรีและโอเพนซอร์ส
⬇️ ดาวน์โหลด APK เวอร์ชันล่าสุด ดูบน GitHub
ขณะนี้เผยแพร่ APK ผ่าน GitHub Releases ต้องใช้ Android 8.0 ขึ้นไปและอุปกรณ์ arm64 (สมาร์ตโฟนรุ่นใหม่เกือบทั้งหมด) ไม่รองรับอีมูเลเตอร์ x86

นี่คืออะไร?

ImageTrans สำหรับ Android คือเวอร์ชัน Androidของซอฟต์แวร์แปลรูปภาพโดยใช้คอมพิวเตอร์ช่วย ImageTrans เหมาะกับสถานการณ์ “เห็นอะไรก็อยากแปลทันที” — หน้ามังงะบนมือถือ เมนูและป้ายข้างทาง ภาพหน้าจอแอป หรือรูปสินค้าทั้งโฟลเดอร์

ไม่ต้องพึ่งคอมพิวเตอร์ตั้งโต๊ะ คุณสามารถเชื่อมต่อเซิร์ฟเวอร์ ImageTrans ระยะไกลเพื่อใช้กระบวนการทำงานเต็มรูปแบบของ ImageTrans หรือทำงานบนมือถือทั้งหมด: OCR ทำงานบนเครื่องและส่งเฉพาะข้อความที่ตรวจจับได้ไปยัง API แปล ต่างจากการแปลภาพหน้าจอทั่วไป ImageTrans สำหรับ Android จะแทนที่ข้อความต้นฉบับด้วยคำแปลและพยายามรักษาการจัดวางเดิมไว้

สี่วิธีในการแปล

🖼️

แปลรูปภาพ

เลือกรูปภาพหนึ่งรูปจากแกลเลอรีหรือไฟล์แล้วแปล แตะพื้นที่ข้อความใดก็ได้เพื่อเทียบต้นฉบับกับคำแปล สลับระหว่างรูปต้นฉบับกับรูปที่แปลแล้ว จากนั้นบันทึกผลลัพธ์ลงแกลเลอรีหรือแชร์

📷

แปลด้วยการถ่ายรูป

เล็งไปที่ป้าย เมนู บรรจุภัณฑ์ เอกสาร หรือสิ่งใดก็ได้ บนตัวอย่างกล้องมีกรอบเลือกที่ลากและซูมได้ แตะ “ถ่ายและแปล” เพื่อจับภาพตัวอย่าง ครอปบริเวณกรอบแล้วแปล โดยไม่บันทึกภาพถ่าย

📁

แปลโฟลเดอร์

เลือกโฟลเดอร์แล้วแปลรูปภาพทั้งหมดในครั้งเดียว คำแปลจะถูกบันทึกเป็น PNG ลงในโฟลเดอร์ย่อย out ภายใต้โฟลเดอร์นั้น โดยคงชื่อไฟล์เดิม เหมาะกับรูปสินค้าอีคอมเมิร์ซ แคตตาล็อกสินค้า และงานแบบกลุ่มอื่น ๆ

🫧

หน้าต่างลอยแปลภาพหน้าจอ

ลูกบอลลอยและกรอบเลือกจะแสดงอยู่เหนือแอปอื่นตลอดเวลา แตะ “แปล” เพื่อแปลเนื้อหาภายในกรอบได้ทันที คำแปลจะแสดงในกรอบ — ส่วนอื่นของหน้าจอไม่ได้รับผลกระทบและยังใช้แอปอื่นได้ตามปกติ ใช้ได้กับทุกแอป รวมถึงเกม: แปลบทสนทนา คำอธิบายไอเทม และเมนูในเกมมือถือได้โดยไม่ต้องออกจากเกม

ออกแบบสำหรับรูปภาพจริง

⚡

OCR บนเครื่อง

ด้วย rapidocr4j (PaddleOCR) และ ONNX Runtime การตรวจจับและจดจำข้อความทำบนมือถือทั้งหมด เร่งความเร็วด้วย OpenCV และไม่ต้องอัปโหลดรูปภาพเมื่อทำ OCR เท่านั้น ภาษาจีน อังกฤษ ญี่ปุ่น และภาษากลุ่มละตินพร้อมใช้ทันที ส่วนโมเดลภาษาเกาหลี อาหรับ รัสเซีย และไทยจะดาวน์โหลดอัตโนมัติเมื่อใช้งานครั้งแรก สำหรับหน้าภาษาญี่ปุ่นสามารถเลือกใช้โมเดลบรรทัดข้อความ YOLO ซึ่งเหมาะกับมังงะที่เขียนแนวตั้ง และยังตรวจหาบอลลูนคำพูดได้พร้อมกัน

🎨

การเรนเดอร์ที่รักษาการจัดวาง

คำแปลใช้เอนจินเรนเดอร์เดียวกับส่วนขยายเบราว์เซอร์ของ ImageTrans: ปรับขนาดตัวอักษรอัตโนมัติ ตรวจจับสีข้อความ จัดการพื้นหลัง รองรับมุมโค้ง ขอบตัวอักษร เงา และการจัดวางข้อความแนวตั้งสำหรับภาษาจีนและญี่ปุ่นกับการจัดวางจากขวาไปซ้าย

💬

บอลลูนคำพูดในมังงะ

บนหน้ามังงะ บรรทัดข้อความในบอลลูนเดียวกันจะถูกรวมเป็นย่อหน้าก่อนแปล บอลลูนจะเรียงตามลำดับการอ่าน: ทีละบรรทัดจากบนลงล่าง สำหรับมังงะญี่ปุ่นแนวตั้งในบรรทัดเดียวกันจะเรียงจากขวาไปซ้าย หาก YOLO ตรวจพบบอลลูนจะใช้เป็น panel โดยตรง หากไม่พบจะคำนวณจากบรรทัดข้อความ

🧵

มังงะแนวยาว

มังงะแนวตั้งที่ยาวมากจะถูกตรวจจับและเรนเดอร์เป็นบล็อกแล้วจึงต่อกลับเข้าด้วยกัน เพื่อหลีกเลี่ยงการใช้หน่วยความจำจนหมดกับรูปยาวทั้งภาพ และหลีกเลี่ยงข้อความเบลอจากการย่อขยาย

🔎

ตรวจจับเท่านั้น

ไม่แปล ทำเพียง OCR และวางข้อความที่ตรวจจับได้กลับในตำแหน่งเดิม เหมาะสำหรับดีบักโมเดล สร้างข้อมูลฝึก และตรวจสอบประสิทธิภาพการตรวจจับจริงของแอปกับรูปภาพที่ยาก

เลือกเอนจินการแปล

🖥️ เซิร์ฟเวอร์ ImageTrans ระยะไกล

เชื่อมต่อเซิร์ฟเวอร์ ImageTrans ที่ทำงานอยู่ที่ใดก็ได้ — บนคอมพิวเตอร์ของคุณหรือโฮสต์ระยะไกล/คลาวด์ — เพื่อใช้การตั้งค่าโปรเจกต์ เอนจิน OCR หน่วยความจำการแปล และคลังศัพท์ของคุณ

  • กระบวนการ ImageTrans เต็มรูปแบบ: ตรวจจับ ลบข้อความ แปล จัดวางข้อความ
  • ผลลัพธ์ดีที่สุด รองรับภาษามากที่สุด
  • ไม่ต้องติดตั้ง ImageTrans บนมือถือ

🤖 OCR บนเครื่อง + API ที่เข้ากันได้กับ OpenAI

OCR ทำบนมือถือ ข้อความที่ตรวจจับได้จะถูกส่งไปยัง API ที่เข้ากันได้กับ OpenAI ใดก็ได้เพื่อแปล

  • รองรับ ChatGPT, Gemini, DeepSeek และบริการที่เข้ากันได้อื่น ๆ
  • ใช้ API Key และโมเดลของคุณเอง
  • เพิ่มพารามิเตอร์คำขอเพิ่มเติมได้ด้วย JSON (ปิดโหมดคิดของ DeepSeek เป็นค่าเริ่มต้น)
  • สมดุลระหว่างความเร็ว คุณภาพ และค่าใช้จ่าย

🆓 OCR บนเครื่อง + MyMemory

ไม่ต้องใช้ API Key ใช้บริการแปลฟรี MyMemory ย่อหน้าที่ยาวจะถูกแบ่งอัตโนมัติเพื่อให้เป็นไปตามข้อจำกัดของ API

  • ฟรีทั้งหมด ประมาณ 50,000 ตัวอักษรต่อวัน
  • เหมาะกับการแปลเร็วในชีวิตประจำวัน
  • จะแจ้งเตือนเมื่อใช้โควตาหมด

ใช้งานร่วมกับส่วนขยายเบราว์เซอร์

หากคุณอ่านมังงะบนเบราว์เซอร์มือถือ ImageTrans สำหรับ Android สามารถทำหน้าที่เป็นเซิร์ฟเวอร์แปลของส่วนขยายเบราว์เซอร์ ImageTrans ได้: มือถือทำ OCR ในเบื้องหลัง ส่งพื้นที่ข้อความ (และคำแปล) กลับไปยังส่วนขยาย แล้วส่วนขยายจึงเรนเดอร์ลงบนหน้าเว็บ

บนมือถือเครื่องเดียวกันเพียงกรอก http://127.0.0.1:51042 ไม่ต้องพึ่ง Wi-Fi หรือข้อมูลมือถือ หรือจะใช้ IP ในวง LAN ของมือถือจากคอมพิวเตอร์ในเครือข่ายเดียวกันก็ได้

เริ่มต้นอย่างไร

  1. ดาวน์โหลดและติดตั้ง APK ดาวน์โหลด APK จาก GitHub Releases และติดตั้ง อาจต้องอนุญาตให้ติดตั้งแอปจากแหล่งที่ไม่รู้จัก
  2. เลือกวิธีแปล ในการตั้งค่า ให้เลือกวิธีแปล: เชื่อมต่อเซิร์ฟเวอร์ ImageTrans ระยะไกล (กรอกที่อยู่เซิร์ฟเวอร์และรหัสผ่านโปรเจกต์) หรือทำ OCR บนมือถือแล้วแปลด้วย API ที่เข้ากันได้กับ OpenAI / MyMemory เมื่อเลือก MyMemory ไม่ต้องใช้ API Key
  3. ตั้งค่าคู่ภาษา เลือกภาษาต้นทางและปลายทาง ภาษาต้นทาง “อัตโนมัติ” จะถือเป็นภาษาญี่ปุ่น ภาษาปลายทาง “อัตโนมัติ” จะถือเป็นภาษาอังกฤษ หรือระบุให้ชัดเจนก็ได้
  4. เริ่มแปล เลือกรูปจากแกลเลอรี ถ่ายรูป เลือกโฟลเดอร์ หรือเปิดหน้าต่างลอยแปลภาพหน้าจอ แอปจะตรวจจับข้อความ แปล และวางคำแปลกลับลงบนรูปภาพ
  5. บันทึกหรือแชร์ บันทึกคำแปลลงแกลเลอรีหรือแชร์ เมื่อแปลโฟลเดอร์เสร็จสามารถเปิดโฟลเดอร์เอาต์พุตได้โดยตรง
