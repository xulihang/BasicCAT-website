## v7.0.0 (2026/11/01)

* พอร์ต ag-psd ไปยัง Java เพื่อใช้สร้าง PSD รองรับการสร้าง PSD ที่มีข้อความแก้ไขได้โดยไม่ต้องพึ่ง Photoshop และบน Linux ช่วยขจัดการพึ่งพา Krita ที่บังคับสำหรับการสร้าง PSD แบบแรสเตอร์
* เปลี่ยนชื่อการตรวจจับบอลลูนคำพูดเป็นการตรวจจับด้วยโมเดลกำหนดเอง
* รองรับโมเดลกำหนดเองแบบเต็มฟังก์ชัน โมเดลเดียวทำงานระบุตำแหน่งข้อความ ตรวจจับช่องภาพ ตรวจจับบอลลูนคำพูด และสร้างมาสก์ได้
* โมเดลกำหนดเองรองรับการใช้โมเดลระบุตำแหน่งของ RapidOCR
* โมเดล japanese-lines ในตัวเปลี่ยนไปใช้โมเดล PPOCR ที่ฝึกสำหรับมังงะญี่ปุ่น
* ลบโมเดลตรวจจับช่องภาพมังงะญี่ปุ่น
* เมื่อไม่ได้เลือกพื้นที่ แล้วคลิกปุ่มรู้จำ จะมีคำแนะนำการใช้งาน
* ค่าเริ่มต้นจะถามว่าจะใช้โมเดลตรวจจับกำหนดเองใด (หากมีหลายโมเดล)
* อัปเดตเทมเพลต เทมเพลตมังงะญี่ปุ่นใช้การเรียงลำดับ XYCut เป็นค่าเริ่มต้น และตั้งค่าพิกเซลขยายการลบข้อความเป็น 20
* พิกเซลขยายการลบข้อความใช้ได้กับการสร้างมาสก์ด้วย
* แก้ไขปัญหาการเรียงลำดับ XYCut อาจลบพื้นที่ข้อความที่มีอยู่แล้ว
* แก้ไขรายการเมนูที่คำอธิบายไม่ถูกต้อง
* แก้ไขปัญหาเมื่อแก้ไขมาสก์ของพื้นที่หนึ่ง อาจทำให้ทั้งภาพสร้างมาสก์ใหม่ทั้งที่ไม่ได้จำเป็น

* เมื่อเรียงลำดับตามช่องภาพ พื้นที่ที่อยู่นอกช่องภาพก็จะถูกเรียงลำดับด้วย
* แก้ไขปัญหาดัชนีเกินขอบเขตของอาร์เรย์ในการเรียงลำดับ XYCut

* แก้ไขปัญหา ROI ไม่สอดคล้องกันเมื่อตรวจสอบว่าภาพซับซ้อนหรือไม่ในการสร้างมาสก์และการลบข้อความ

## v4.2.0 (2025/09/21)

* ฟังก์ชันปรับขนาดฟอนต์อัตโนมัติของเอนจินข้อความแนวตั้งแม่นยำขึ้น
* การตรวจจับทิศทางข้อความใช้สัดส่วนภาพเป็นเกณฑ์เป็นค่าเริ่มต้น
* เพิ่มรายการเมนูเปิดไดเรกทอรีซอฟต์แวร์
* เมื่อแปลเป็นชุด การดำเนินการรวมพื้นที่จะดำเนินการหลังการตรวจจับบอลลูนคำพูดด้วย
* เมื่อรู้จำด้วย OCR แบบรู้จำล้วนสามารถใช้กับข้อความแถบยาวเท่านั้น
* RapidOCR รองรับการคืนผลลัพธ์ระดับอักขระ
* มี mangaOCR เวอร์ชัน ONNX เป็นค่าเริ่มต้น
* ปรับปรุงเทมเพลตตาม OCR ในตัวใหม่
* ปล่อย Mat ของ OpenCV ทันทีเพื่อปรับปรุงการใช้หน่วยความจำ
* การรวมพื้นที่แบบแบตช์เปลี่ยนเป็นการดำเนินการที่ไม่เกี่ยวข้องกับ UI
* โหลดไลบรารีไดนามิกของ ONNXRuntime เป็นค่าเริ่มต้น
* เพิ่มการลบพื้นที่ที่ไม่ใช่ข้อความ (OCR) ไปยังขั้นตอนการทำงานกำหนดเอง
* เมื่อ OCR พื้นที่เดียว ให้ครอบตัดตามตำแหน่งที่จัดเก็บแทนตำแหน่งของคอนโทรล
* RapidOCR แก้ไขลำดับเป็นค่าเริ่มต้นเมื่อรู้จำพื้นที่เดียว
* ตัวเลือกปรับลำดับเมื่อรู้จำพื้นที่เดียวไม่มีผลกับเอนจินรู้จำล้วนอย่าง mangaOCR
* แก้ไขปัญหาลำดับข้อความของ Baidu OCR เวอร์ชันแม่นยำ
* แก้ไขปัญหาการแปลเป็นภาษาท้องถิ่นของรายการที่มีพารามิเตอร์ในขั้นตอนการทำงานกำหนดเอง
* แก้ไขปัญหาการเลือกข้อความผิดพลาดเมื่อเปิดโหมดจัดหน้าแต่ยังไม่ได้ดูการแปล
* แก้ไขปัญหาไม่สามารถเพิ่มรายการทั่วไปเมื่อเปิดใช้การเพิ่มพารามิเตอร์ในขั้นตอนการทำงานกำหนดเอง
