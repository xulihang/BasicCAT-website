What Is It?

ImageTrans Android is the Android version of ImageTrans, the computer-aided image translation software. It is designed for the cases where you want to translate an image right when you are looking at it — a comic page on your phone, a menu or sign on the street, an app screenshot, or a whole folder of product images.

It is not tied to a desktop computer. You can either connect it to a remote ImageTrans server to use the full ImageTrans pipeline, or run everything on the phone itself — OCR is done locally, and only the recognized text is sent to a translation API. Unlike a simple screenshot translator, ImageTrans Android replaces the original text with the translation, matching the original layout as closely as possible.

Four Ways to Translate

🖼️

Image Translation

Pick an image from the gallery or file picker and translate it. Tap any text box to compare the original with the translation, toggle between the original and translated image, then save the result to your gallery or share it.

📷

Camera Translation

Point the camera at anything — signs, menus, packaging, documents. A draggable, resizable selection box sits on top of the live preview. Tap "Capture and Translate" to grab a frame, crop the selection and translate it. No photo is saved.

📁

Folder Translation

Select a folder and translate all the images in it in one go. Translated images are saved as PNG files in an out subfolder, keeping the original file names. Handy for e-commerce listings and product catalogs.

🫧

Screenshot Translation Overlay

A floating button and a persistent selection box stay on top of other apps. Tap "Translate" and the selected area is translated in place, right inside the selection — the rest of the screen keeps working normally. It works with any app, including games: translate dialogue, item descriptions or menus of mobile games without leaving the game.

Built for Real Images

⚡

On-Device OCR

Text detection and recognition run locally with PaddleOCR (via rapidocr4j) and ONNX Runtime, accelerated with OpenCV. No image ever needs to be uploaded just for OCR. Chinese, English, Japanese and Latin-script languages work out of the box; Korean, Arabic, Russian and Thai models download on first use.

🎨

Layout-Aware Rendering

Translations are typeset with the same rendering engine as the ImageTrans browser extension: automatic font sizing, text color detection, backgrounds, rounded corners, outlines and shadows, plus vertical writing for Japanese and Chinese and right-to-left layouts.

🧵

Long Webtoon Strips

Extremely long vertical strips are processed block by block for both recognition and rendering, then stitched back together — so tall manhwa and webtoon pages do not run out of memory or get downscaled into mush.

🔎

Recognize Only

Run OCR without translation and redraw the recognized text in place. Useful for debugging models or training data, and for checking how well the app reads a difficult image.

Choose Your Translation Engine

🖥️ Remote ImageTrans Server

Connect to an ImageTrans server running anywhere — on your own computer or a remote/cloud host — so the app uses your project settings, OCR engines, translation memory and glossary.

  • Full ImageTrans pipeline: detection, text removal, translation, lettering
  • Best quality and widest language support
  • No ImageTrans installation needed on the phone

🤖 Local OCR + OpenAI-Compatible API

OCR runs on the phone, then the recognized text is sent to any OpenAI-compatible endpoint for translation.

  • ChatGPT, Gemini, DeepSeek, or any compatible service
  • Bring your own API key and model
  • Good balance of speed, quality and cost

🆓 Local OCR + MyMemory

No API key needed. Translation uses the free MyMemory service, with long paragraphs split automatically to fit its request limits.

  • Free to use, about 50,000 characters per day
  • Ideal for quick, everyday translations
  • You are notified when the daily quota runs out

Works with the Browser Extension

If you browse comics or manga in a mobile browser, ImageTrans Android can act as the translation server for the ImageTrans browser extension. The phone performs OCR in the background and returns text boxes (and translations) to the extension, which renders them on the page.

Use it on the same phone with http://127.0.0.1:51042 — no Wi-Fi or mobile data required — or from a computer on the same network with the phone's IP address.

How to Get Started

  1. Download and install the APK Download the APK from GitHub Releases (v0.1.1) and install it on your phone. You may need to allow installing apps from unknown sources.
  2. Choose a translation method In Settings, choose how to translate: connect to a remote ImageTrans server (enter its address and project password), or run fully locally with Local OCR + an OpenAI-compatible API or Local OCR + MyMemory. For MyMemory, no API key is required.
  3. Set the language pair Pick the source and target languages. Leave the source on "Auto" for Japanese and the target on "Auto" for English, or choose them explicitly.
  4. Translate Pick an image from the gallery, take a photo, choose a folder, or turn on the screenshot overlay. The app detects the text, translates it and lays it back onto the image.
  5. Save or share Save translated images to your gallery, share them, or open the output folder for folder translations.

Requirements & Limits

📱

arm64 Device

Runs on Android 8.0 or later (Android 8 to 10 use the system screen-capture permission for screenshot translation; Android 11+ uses an accessibility service). Native OCR libraries are built for arm64-v8a, so virtually all modern Android phones are supported. x86_64 emulators cannot run OCR.

🌐

Network

In local modes OCR runs entirely on the phone and only the text is sent to the translation API. The server mode needs access to your ImageTrans server; Korean, Arabic, Russian and Thai OCR models are downloaded on first use.

🔋

Background Use

The screenshot overlay and extension server run in the foreground service. On some Chinese ROMs you may need to allow background activity and disable battery optimization.
