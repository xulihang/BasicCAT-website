ImageTrans 安卓版

在手机上直接翻译图片、照片和屏幕上的文字——游戏里也可以。ImageTrans 安卓版自动识别文字、进行翻译，并把译文按原位置回填到图片上——不需要电脑。

🤖 Android 8+ 🆓 免费开源
⬇️ 下载最新版 APK 在 GitHub 上查看
目前通过 GitHub Releases 发布 APK。需要 Android 8.0 及以上、arm64 设备（绝大多数现代手机），不支持 x86 模拟器。

这是什么？

ImageTrans 安卓版是计算机辅助图片翻译软件 ImageTrans 的安卓版本。它适合“看到什么就想马上翻译什么”的场景——手机上的漫画页、街边的菜单和招牌、App 截图，或者一整个文件夹的商品图。

它不依赖桌面电脑。既可以连接远程的 ImageTrans 服务器，使用完整的 ImageTrans 处理流程；也可以完全在手机本地运行：OCR 在本地完成，只把识别出的文本发送给翻译 API。与普通的截图翻译不同，ImageTrans 安卓版会用译文替换原文，并尽量还原原有的排版。

四种翻译方式

🖼️

图片翻译

从相册或文件选择一张图片并翻译。点击任意文字框即可对照原文和译文，可以在原图与译文之间切换，然后把结果保存到相册或分享出去。

📷

拍照翻译

对准招牌、菜单、包装、文档等任何内容。相机预览上有一个可拖动、可缩放的选框，点“拍摄并翻译”即可截取预览画面、裁剪选框区域并翻译，不会保存照片。

📁

文件夹翻译

选择一个文件夹，一次性翻译其中的所有图片。译文以 PNG 格式保存到该文件夹下的 out 子文件夹，并保留原文件名。适合电商商品图、产品目录等批量场景。

🫧

截屏翻译悬浮窗

悬浮球和选框常驻在其他 App 之上。点“翻译”即可直接翻译选框内的内容，译文显示在选框里——框外屏幕不受影响，可以照常使用其他 App。适用于任何 App，包括游戏：不用切出游戏，就能翻译手游的对话、物品说明和菜单。

为真实图片而设计

⚡

本地 OCR

借助 rapidocr4j（PaddleOCR）和 ONNX Runtime，文字检测与识别全部在手机上完成，并由 OpenCV 加速，仅做 OCR 时无需上传图片。中、英、日及拉丁系语言开箱即用，韩、阿、俄、泰模型首次使用时自动下载。日文页面可选 YOLO 文字行模型，适合竖排的漫画，并能同时找出漫画气泡。

🎨

还原排版的渲染

译文使用与 ImageTrans 浏览器扩展相同的渲染引擎：自动调整字号、检测文字颜色、处理背景，支持圆角、描边、阴影，以及中日文竖排和从右到左的排版。

💬

漫画气泡

漫画页里同一个气泡中的文字行会合并成一段再翻译，气泡之间按阅读顺序排列：按行从上到下，竖排日漫同一行从右到左。有 YOLO 找到的气泡时直接用它作为 panel，没有时由文字行推算。

🧵

长条漫

超长竖版漫画会分块识别、分块渲染后再拼接，避免整张长图耗尽内存，也不会因为缩放而让文字糊成一片。

🔎

仅识别

不翻译，只做 OCR，并把识别出的文字回填到原位置。适合调试模型、制作训练数据，或检查 App 对某张难图的实际识别效果。

选择翻译引擎

🖥️ 远程 ImageTrans 服务器

连接运行在任何位置的 ImageTrans 服务器——自己电脑上或远程/云端主机——使用你的项目设置、OCR 引擎、翻译记忆和术语库。

  • 完整的 ImageTrans 流程：检测、抹字、翻译、排版
  • 效果最好，支持的语言最多
  • 手机上无需安装 ImageTrans

🤖 本地 OCR + OpenAI 兼容接口

OCR 在手机上完成，识别出的文本交给任意 OpenAI 兼容接口翻译。

  • 支持 ChatGPT、Gemini、DeepSeek 等兼容服务
  • 使用你自己的 API Key 和模型
  • 可用 JSON 添加额外请求参数（默认关闭 DeepSeek 的思考）
  • 速度、质量与成本兼顾

🆓 本地 OCR + MyMemory

无需 API Key，使用免费的 MyMemory 翻译服务，长段落会自动切分以满足接口限制。

  • 完全免费，每天约 5 万字符
  • 适合日常快速翻译
  • 额度用完后会提示

与浏览器扩展配合使用

如果你用手机浏览器看漫画，ImageTrans 安卓版可以作为ImageTrans 浏览器扩展的翻译服务器：手机在后台完成 OCR，把文字框（以及译文）返回给扩展，由扩展渲染到页面上。

同一台手机上填 http://127.0.0.1:51042 即可，不依赖 Wi-Fi 或移动数据；也可以在同一网络中的电脑上使用手机的局域网 IP。

如何开始

  1. 下载并安装 APK 从 GitHub Releases 下载 APK 并安装。可能需要允许安装未知来源的应用。
  2. 选择翻译方式 在设置中选择翻译方式：连接远程 ImageTrans 服务器（填写服务器地址和项目密码），或在手机本地完成 OCR 后再用 OpenAI 兼容接口 / MyMemory 翻译。选择 MyMemory 时无需 API Key。
  3. 设置语言对 选择源语言和目标语言。源语言“自动”按日语处理，目标语言“自动”按英语处理，也可以明确指定。
  4. 开始翻译 从相册选图、拍照、选择文件夹，或开启截屏翻译悬浮窗。App 会识别文字、翻译，并把译文回填到图片上。
  5. 保存或分享 把译文保存到相册或分享出去；文件夹翻译完成后可以直接打开输出目录。

系统要求与限制

📱

arm64 设备

支持 Android 8.0 及以上。本地 OCR 库只提供 arm64-v8a 版本，现代 Android 手机基本都支持。x86_64 模拟器无法运行 OCR。

🌐

网络

本地模式下 OCR 完全在手机上完成，只把文本发送给翻译 API。服务器模式需要能访问你的 ImageTrans 服务器；韩、阿、俄、泰的 OCR 模型首次使用时需要下载。

🔋

后台运行

截屏翻译悬浮窗和扩展用的翻译服务器依赖前台服务运行。部分国产 ROM 需要允许后台活动并关闭电池优化。
