## v1.6.2 (2026/08/30)

* Обновлены плагины перевода ChatGPT и DeepSeek
* Добавлен бесплатный плагин LLM
* Исправлена проблема, из-за которой при разделении текста в переводе ошибочно использовался исходный текст


## v1.6.1 (2026/05/01)

* Добавлен FunASR
* Исправлена ошибка разбора экспортированного SRT, когда результат распознавания состоял только из цифр
* Исправлена проблема, из-за которой настройка размера шрифта субтитров не применялась при воспроизведении аудиофайлов
* Исправлена проблема, из-за которой фокус переключался при нажатии пробела или движении мыши в текстовом поле

## v1.6.0 (2026/04/28)

* Добавлен Qwen3-ASR
* Больше вариантов объединения строк: по знакам препинания, с проверкой времени
* Настройка нижнего смещения субтитров
* Проверка установки или работы плагинов ASR
* Исправлена ошибка при открытии аудиофайлов

## v1.5.5 (2025/10/21)

* Поддержка Windows 7
* При сбое загрузки VLC выводится сообщение об ошибке
* Исправлена ошибка перехода при щелчке по осциллограмме, когда она отключена
* Исправлена проблема, из-за которой после приостановки воспроизведения выбранных строк состояние «Следовать за прогрессом» не восстанавливалось

## v1.5.4 (2025/10/19)

* Исправлена ошибка при щелчке правой кнопкой мыши по области воспроизведения, когда видео не открыто
* VLC включён по умолчанию

## v1.5.3 (2025/07/06)

* Добавлена настройка времени перемотки вперёд
* Добавлен пункт меню для воспроизведения каждой строки
* Исправлены ошибки

## v1.5.2 (2025/05/18)

* Добавлен генератор видео без субтитров
* Поддержка перехода по щелчку на осциллограмме

## v1.5.1 (2025/05/11)

* При воспроизведении выделенного отключается «Следовать за прогрессом»
* Выравниватель поддерживает выравнивание части текста
* Добавлены настройки субтитров: формат, соответствие ширине видео
* Добавлен исполнитель FFmpeg
* Новый вариант экспорта: видео с вшитыми субтитрами (с помощью FFmpeg)

## v1.5.0 (2025/05/02)

* Новые функции: разделение и объединение строк
* В разделитель предложений добавлена кнопка автоматического разделения предложений на основе SRX
* Новый режим разделения и объединения строк
* Новая кнопка быстрого перевода
* Новые настройки CSS для текста субтитров
* Исправлена передача дополнительных параметров при распознавании всего файла с помощью Whisper
* Улучшены сообщения об ошибках Whisper

## v1.4.1 (2025/04/04)

* Новый вариант импорта и экспорта в TXT
* Новые параметры импорта текста из SRT
* Новый плагин DeepSeek
* Тайм-аут ChatGPT увеличен до 2 минут

## v1.4.0 (2025/03/01)

* Добавлено преобразование между упрощённым и традиционным китайским
* Добавлен извлекатель кадров
* Добавлены пункты меню для перехода и воспроизведения
* Добавлен пункт контекстного меню для распознавания выделенного
* Исправлена проблема с кодом китайского языка в Whisper

## v1.3.0 (2025/02/22)

* Добавлен выравниватель для выравнивания распознанной временной шкалы с имеющимся текстом (выравнивание текста и аудио)
* Поддержка импорта и экспорта XLIFF
* Поддержка импорта двуязычных SRT
* Новая настройка проекта для дополнительных параметров распознавания речи
* Новый пункт меню для обмена исходного и переведённого текста
* Новый параметр распознавания речи: не разделять аудио
* В Windows при первом запуске спрашивает, включать ли GPU
* Прочие исправления ошибок

## v1.2.0 (2025/02/09)

* Добавлена настройка точного воспроизведения выделенного
* Добавлен голосовой ввод
* Добавлен разделитель предложений
* Пакетный переводчик поддерживает экспорт SRT
* Перед пакетным изменением временной шкалы запрашивается диапазон для изменения
* Исправлено смещение при отрисовке осциллограммы
* Прочие исправления ошибок

## v1.1.0 (2025/02/04)

* Добавлена настройка размера шрифта субтитров
* Добавлена настройка использования GPU
* Добавлена настройка проекта для подсказок
* Добавлен пакетный перевод
* Добавлена функция общего смещения временной шкалы
* Добавлены пункты меню для перемещения выбранных строк вверх и вниз
* Текст прогресса использует формат hh:mm:ss
* В macOS сочетания клавиш используют клавишу Command
* Поддержка быстрого удаления выбранной строки клавишей Delete
* Вставка новой строки после выбранной
* В macOS и Linux предупреждение о том, что путь не должен содержать пробелов
* Исправлена проблема центрирования субтитров
* Исправлены проблемы локализации

## v1.0.0 (2025/01/27)
