**Последнее обновление: 19 июля 2026 г.**

ImageTrans уважает вашу конфиденциальность. Настоящая политика конфиденциальности описывает, как расширение ImageTrans для браузера обрабатывает ваши данные.

## Изображения

Расширение обрабатывает только те изображения, которые вы явно выбрали для перевода.

Когда вы начинаете перевод, выбранное изображение загружается на настроенный вами сервер перевода. Сервер обрабатывает изображение и возвращает результат перевода.

Расширение не загружает никакие изображения без вашего действия.

## Личные данные не собираются

Расширение не собирает, не хранит и не передаёт:

- историю просмотров;
- персональные данные;
- пароли;
- платёжные данные;
- электронную почту;
- контакты;
- данные о местоположении.

## Хранение данных

Изображения могут временно храниться на сервере перевода только во время обработки вашего запроса на перевод и удаляются по окончании обработки.

## Передача данных

Изображения передаются только на сервер перевода, используемый для выполнения запрошенного перевода.

В зависимости от ваших настроек этим сервером может быть:

- официальный сервер ImageTrans;
- собственный сервер ImageTrans, который вы развернули сами.

При использовании собственного сервера порядок обработки и хранения загруженных изображений определяет владелец сервера.

Расширение не продаёт и не передаёт пользовательские данные рекламодателям или другим третьим сторонам.
