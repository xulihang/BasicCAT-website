Что такое расширение ImageTrans для браузера?

Расширение ImageTrans для браузера переносит возможности перевода изображений на основе ИИ прямо в ваш браузер. Оно обнаруживает текст на изображениях веб-страниц (комиксах, плакатах, скриншотах, брошюрах и т. п.) и автоматически заменяет его переведённой версией.

Основываясь на PaddleOCR и серверной части настольного приложения ImageTrans, расширение сочетает передовую технологию OCR с нейронным машинным переводом, обеспечивая точные переводы с учётом контекста.

Основные возможности

🖱️

Перевод по правому клику

Щёлкните правой кнопкой мыши по любому изображению на веб-странице, выберите «Перевести изображение» — и сразу получите переведённую версию.

⌨️

Горячие клавиши

Нажмите Ctrl+Shift+F, чтобы перевести изображение под курсором — быстро и эффективно.

🔄

Автоматический перевод

Если включить автоматический перевод, изображения будут переводиться при загрузке страницы. Идеально для чтения длинных комиксов.

📸

Перевод скриншотов

Захватите область экрана в браузере для перевода — подходит для изображений, которые нельзя скачать, или для перевода только части изображения.

🤖

Гибкие варианты перевода

Сочетайте любую серверную часть OCR (ImageTrans или PaddleOCR) с API, совместимым с OpenAI (ChatGPT, Gemini, DeepSeek), или со встроенными движками перевода для достижения наилучшего результата.

🀄

Аннотации произношения

Добавляйте фуригану к японскому тексту и пиньинь к китайскому — отличный помощник для изучающих языки.

Как использовать

  1. Установите расширение Добавьте его из Chrome Web Store, дополнений Firefox или магазина дополнений Microsoft Edge. 📱 Мобильные устройства: на iOS можно запускать расширения Chrome или Firefox в браузере Orion. На Android можно использовать Firefox для Android, Edge или браузер Kiwi.
  2. Настройте серверную часть Подключитесь к серверу ImageTrans, используйте встроенный PaddleOCR или укажите собственный ключ API, совместимого с OpenAI.
  3. Начните переводить Щёлкните правой кнопкой по изображению → «Перевести изображение». Также можно включить автоматический перевод, чтобы все изображения переводились при загрузке страницы; использовать функцию скриншота для перевода части экрана или функцию камеры, чтобы сфотографировать и перевести в реальном времени. Готово!

Как это работает

🔌 С настольной версией ImageTrans (рекомендуется)

  • ImageTrans выполняет весь процесс: обнаружение → OCR → удаление текста → перевод → рендеринг
  • Наилучшая точность, широчайшая языковая поддержка и богатые возможности редактирования
  • Расширение отправляет изображение в ImageTrans, а затем сразу показывает готовый результат
  • Требуется, чтобы ImageTrans работал локально или на сервере

🧩 Без ImageTrans (полностью в браузере)

  • Расширение самостоятельно выполняет весь процесс во фронтенде: OCR (PaddleOCR) → перевод → рендеринг
  • Не требует сервера и установки какого-либо программного обеспечения — полностью автономно
  • Бесплатно и конфиденциально
  • Точность, скорость и выбор языков несколько ограничены

Варианты перевода

Следующие способы перевода доступны в обоих режимах. При использовании API, совместимого с OpenAI, вместе с ImageTrans, ImageTrans отвечает только за OCR, а перевод и рендеринг выполняет расширение во фронтенде.

🌐 Встроенный перевод ImageTrans

  • Доступен при подключении к ImageTrans
  • Поддерживает различные движки перевода (Google, DeepL, Baidu и др.)
  • Включает память переводов, управление терминологией и поиск по корпусу

🤖 API, совместимый с OpenAI

  • Используйте ChatGPT, Gemini, DeepSeek или любой совместимый API
  • Работает с ImageTrans и без него — используйте собственный ключ API
  • Гибкие настраиваемые промпты для более точного перевода
  • Вместе с ImageTrans: ImageTrans выполняет только OCR, а расширение — перевод и рендеринг

🆓 MyMemory (бесплатно)

  • Бесплатный API машинного перевода без ключа
  • Подходит для быстрых разовых переводов

О настольной версии ImageTrans

ImageTrans — полнофункциональное настольное программное обеспечение для компьютерного перевода изображений. Расширение для браузера подходит для быстрого перевода на месте, а настольная версия ImageTrans даёт вам полный контроль над всем рабочим процессом перевода.

🎛️

Мощные возможности настройки

Точно настраивайте каждый этап: выбирайте из множества OCR-движков, настраивайте алгоритмы обнаружения и параметры рендеринга, чтобы точно соответствовать вашим требованиям.

✏️

Ручное редактирование

Корректируйте области текста, исправляйте результаты OCR, редактируйте перевод, подстраивайте положение текста — когда автоматизации недостаточно, всё под вашим контролем.

🎨

Экспорт в PSD

Экспортируйте переведённые изображения в файлы Photoshop (PSD) с отдельными слоями текста, чтобы легко передать их дизайнеру на последующую обработку.

📦

Пакетная обработка

Переводите сотни изображений за один раз. Поддерживает импорт и экспорт данных через Excel, Word или XLIFF, бесшовно интегрируясь с другими инструментами перевода.

Что можно переводить?

Комиксы и вебтуны
