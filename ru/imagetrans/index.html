ImageTrans — это инструмент для компьютерной транскрипции и перевода текста на изображениях. Он использует технологию OCR для автоматического обнаружения и распознавания текста, автоматически удаляет оригинал и вставляет перевод, а также обладает алгоритмами объединения и обнаружения областей текста, разработанными специально для комиксов.

Помимо использования в качестве переводчика изображений для плакатов и комиксов, ImageTrans можно применять для чтения изображений, транскрипции текста, OCR-перевода скриншотов, преобразования PDF в markdown и перевода, создания двухслойных PDF с поиском из отсканированных документов, а также для разметки данных для глубокого обучения и других задач.

ImageTrans — результат моей магистерской диссертации: разработка и реализация инструмента для помощи в переводе комиксов.

Ключевые возможности

🔍

Точное определение областей текста

Поддерживает различные методы, такие как обнаружение текста в естественной сцене, обнаружение объектов и эвристические методы, а также включает алгоритмы объединения и обнаружения областей текста, разработанные специально для речевых облачков в комиксах. Обнаруживает звукоподражания, речевые облачка и панели манги и выполняет попиксельную сегментацию масок.

📖

OCR-распознавание с несколькими движками

Поддерживает различные OCR-движки и пользовательские плагины, охватывающие основные языки мира. Поддерживает распознавание вертикального китайского и японского текста с определением порядка чтения с помощью анализа вёрстки. Можно использовать большие языковые модели для проверки и повышения точности OCR.

🌐

Перевод

Машинный перевод: поддерживает различные движки машинного перевода и большие ИИ-модели (ChatGPT, Gemini, DeepSeek и др.). Использование контекстной информации для повышения качества перевода.

Вспомогательные функции: параллельное сравнение нескольких результатов, память переводов, поиск по корпусу, управление терминологией, аннотации каной и пиньинем, а также система поиска звукоподражаний в комиксах.

🧹

Удаление текста

Поддерживает алгоритмы и ИИ-модели, такие как бинаризация, PatchMatch, Lama Inpaint, Gemini Nano Banana, для создания масок текста и удаления текста. Сохранение полутоновых точек манги при удалении текста.

🎨

Вёрстка текста

  • Автоматическая настройка размера шрифта
  • Оптимизация переносов строк для языков с пробелами (например, при переводе с японского на английский)
  • Обработка пунктуации в начале или конце строки
  • Форматированный текст и стили шрифта (аналог системы стилей Word)
  • Определение цвета текста
  • Определение угла поворота
  • Вёрстка вертикального текста
🖌️

Экспорт в PSD

Сохраняет результат в виде файла Photoshop PSD с отдельными слоями текста, что упрощает последующую обработку дизайнером.

📦

Пакетная обработка

Обрабатывает сотни изображений за один раз. Поддерживает настраиваемые рабочие процессы, вызов из командной строки и многопроцессную параллельную обработку для быстрого массового производства.

🖥️

Интуитивный и мощный интерфейс

Визуальный редактор с предварительным просмотром в реальном времени. Пошаговое выполнение OCR, перевода, ретуши, набора текста, поиска с заменой, настраиваемых рабочих процессов и других операций — единый интерфейс, мощный и простой в использовании.

Дополнительные возможности

📄

Перевод PDF и преобразование в Markdown

Переводите PDF и преобразуйте их в Markdown; можно выводить исходный текст, перевод или двуязычный параллельный вариант, сохраняя структуру многоколоночных статей, формул, таблиц и сносок. Создание двухслойных PDF с поиском.

🖥️

Перевод экрана в реальном времени

Захват и перевод любой области экрана в реальном времени. Автоматически обнаруживает изменения содержимого и поддерживает мгновенное сопоставление с памятью переводов.

🎬

Извлечение вшитых субтитров из видео

Извлечение вшитых субтитров из видео с помощью быстрого OCR-обнаружения текста — быстро и точно, с выводом в файл субтитров SRT.

📷

Сканирование и улучшение документов

Поддерживает интегрированное сканирование TWAIN / WIA / SANE / ICA / eSCL. Очистка, выравнивание и улучшение отсканированных книг для наилучшей предварительной обработки изображений.

Удобство использования

⌨️

Горячие клавиши

Почти все операции поддерживают горячие клавиши, поэтому не нужно постоянно переключаться на мышь — быстрый и эффективный рабочий процесс.

💻

Командная строка и вызов API

Позволяет вызывать ImageTrans из командной строки для выполнения автоматизированных задач. Может работать как API-сервер, предоставляя услуги перевода по HTTP, что упрощает интеграцию с любым приложением или сервисом.

⚙️

Настраиваемые рабочие процессы

Свободно комбинируйте этапы обработки, такие как обнаружение, OCR, перевод и рендеринг, чтобы создавать автоматизированные рабочие процессы под ваши задачи.

🤖

Интеграция с AI Agent

Благодаря ImageTrans Skills AI-агенты могут вызывать ImageTrans — структурированные определения навыков позволяют агентам на базе LLM программно выполнять задачи перевода.

📐

Умное выравнивание и поиск с заменой

При перемещении текстовых блоков отображаются направляющие выравнивания, поддерживается пакетное выравнивание по позиции исходного текста, а также встроенная функция поиска и замены. Подходит для перевода изображений интернет-магазинов и подобных сценариев.
