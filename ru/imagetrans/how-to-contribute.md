Вы можете помочь улучшить ImageTrans следующими способами:

1. Перевод документации

	Документация ImageTrans создана с помощью Sphinx и размещена на readthedocs.

	Репозиторий документации: <https://github.com/xulihang/ImageTrans-docs>

	Необходимо извлечь po-файлы с помощью инструмента локализации Sphinx и перевести их.

2. Перевод интерфейса программы

	ImageTrans использует [B4XLocalizator](https://www.b4x.com/android/forum/threads/b4x-localizator-localize-your-b4x-applications.68751/) для локализации, требуется перевести файл strings.xlsx. После завершения перевода его нужно преобразовать в strings.db, чтобы программа могла его использовать.
	
	strings.xlsx можно скачать здесь: <https://github.com/xulihang/ImageTrans_l10n_en/releases/tag/strings>

3. Разработка плагинов

	ImageTrans использует ABPlugin для разработки плагинов. Код существующих плагинов: <https://github.com/xulihang/ImageTrans_plugins>
	
4. Предложения

	Перейдите на [страницу issues](https://github.com/xulihang/ImageTrans-docs/issues) документации, чтобы оставить предложение.
