ImageTrans для Android

Переводите изображения, фотографии и текст на экране прямо на телефоне — даже в играх. ImageTrans для Android автоматически распознаёт текст, переводит его и возвращает перевод на исходное место поверх изображения — компьютер не нужен.

🤖 Android 8+ 🆓 Бесплатно и с открытым кодом
⬇️ Скачать последнюю версию APK Посмотреть на GitHub
Сейчас APK распространяется через GitHub Releases. Требуется Android 8.0 или новее и устройство с arm64 (подавляющее большинство современных телефонов); эмуляторы x86 не поддерживаются.

Что это такое?

ImageTrans для Android — это Android-версия программы для машинного перевода изображений ImageTrans. Она подходит для ситуаций «увидел и сразу захотел перевести»: страницы комиксов на телефоне, меню и вывески на улице, скриншоты приложений или целая папка с фотографиями товаров.

Она не требует настольного компьютера. Можно подключиться к удалённому серверу ImageTrans и использовать полный процесс обработки ImageTrans, а можно работать полностью локально на телефоне: OCR выполняется на устройстве, а на API перевода отправляется только распознанный текст. В отличие от обычного перевода скриншотов, ImageTrans для Android заменяет исходный текст переводом и по возможности сохраняет исходную вёрстку.

Четыре способа перевода

🖼️

Перевод изображений

Выберите изображение из галереи или файлов и переведите его. Нажмите на любую область текста, чтобы сравнить оригинал и перевод, переключитесь между исходным и переведённым изображением, а затем сохраните результат в галерею или поделитесь им.

📷

Перевод по фото

Наведите камеру на что угодно: вывески, меню, упаковки, документы. На предпросмотре камеры есть рамка, которую можно перетаскивать и масштабировать; нажмите «Снять и перевести», чтобы захватить предпросмотр, обрезать область рамки и перевести её — фото при этом не сохраняется.

📁

Перевод папок

Выберите папку и переведите все изображения в ней за один раз. Переводы сохраняются в формате PNG в подпапке out внутри этой папки с сохранением исходных имён файлов. Подходит для изображений товаров для электронной коммерции, каталогов и других пакетных задач.

🫧

Плавающее окно перевода скриншотов

Плавающий шарик и рамка всегда отображаются поверх других приложений. Нажмите «Перевести», чтобы напрямую перевести содержимое рамки: перевод отображается внутри рамки, остальной экран не затрагивается, и вы можете продолжать пользоваться другими приложениями. Работает в любом приложении, включая игры: диалоги, описания предметов и меню мобильных игр можно переводить, не выходя из игры.

Создано для реальных изображений

⚡

Локальный OCR

Благодаря rapidocr4j (PaddleOCR) и ONNX Runtime обнаружение и распознавание текста полностью выполняются на телефоне с ускорением OpenCV, и при работе только с OCR загружать изображение не нужно. Китайский, английский, японский и языки с латинской письменностью работают сразу; модели для корейского, арабского, русского и тайского скачиваются автоматически при первом использовании. Для японских страниц можно дополнительно включить модель текстовых строк YOLO — она подходит для комиксов с вертикальным текстом и одновременно находит речевые облачка.

🎨

Рендеринг с сохранением вёрстки

Перевод использует тот же движок рендеринга, что и браузерное расширение ImageTrans: автоматически подбирает размер шрифта, определяет цвет текста, обрабатывает фон и поддерживает скруглённые углы, обводку, тени, а также вертикальную вёрстку для китайского и японского и вёрстку справа налево.

💬

Речевые облачка в комиксах

На странице комикса строки текста из одного речевого облачка объединяются в абзац и только затем переводятся, а облачка упорядочиваются по порядку чтения: построчно сверху вниз, а в вертикальной японской манге — справа налево в пределах строки. Если YOLO нашёл облачка, они напрямую используются как panel; если нет — они вычисляются по строкам текста.

🧵

Длинные вебтуны

Очень длинные вертикальные комиксы распознаются и рендерятся по блокам, а затем склеиваются, чтобы огромное изображение не исчерпало память и текст не становился размытым из-за масштабирования.

🔎

Только распознавание

Без перевода: выполняется только OCR, а распознанный текст возвращается на исходное место. Подходит для отладки моделей, создания обучающих данных или проверки того, как приложение распознаёт сложное изображение.

Выбор движка перевода

🖥️ Удалённый сервер ImageTrans

Подключитесь к серверу ImageTrans, работающему где угодно — на вашем компьютере или на удалённом либо облачном хосте, — и используйте настройки проекта, движки OCR, память переводов и глоссарий.

  • Полный процесс ImageTrans: обнаружение, удаление текста, перевод и вёрстка
  • Лучший результат и наибольшая поддержка языков
  • Устанавливать ImageTrans на телефон не нужно

🤖 Локальный OCR + интерфейс, совместимый с OpenAI

OCR выполняется на телефоне, а распознанный текст отправляется на перевод в любой интерфейс, совместимый с OpenAI.

  • Поддержка ChatGPT, Gemini, DeepSeek и других совместимых сервисов
  • Используйте свой API-ключ и свою модель
  • Можно добавлять дополнительные параметры запроса в JSON (режим рассуждения DeepSeek по умолчанию отключён)
  • Баланс скорости, качества и стоимости

🆓 Локальный OCR + MyMemory

API-ключ не нужен: используется бесплатный сервис перевода MyMemory, который автоматически разбивает длинные абзацы, чтобы соблюсти ограничения интерфейса.

  • Полностью бесплатно, около 50 000 символов в день
  • Подходит для быстрого повседневного перевода
  • При исчерпании лимита появится уведомление

Совместное использование с браузерным расширением

Если вы читаете комиксы в мобильном браузере, ImageTrans для Android может выступать в роли сервера перевода для браузерного расширения ImageTrans: телефон выполняет OCR в фоновом режиме и возвращает расширению области текста (и переводы), которые расширение отрисовывает на странице.

На том же телефоне достаточно указать http://127.0.0.1:51042 — Wi-Fi или мобильные данные не нужны; можно также использовать локальный IP телефона на компьютере в той же сети.

С чего начать

  1. Скачайте и установите APK Скачайте APK со страницы GitHub Releases и установите его. Возможно, потребуется разрешить установку приложений из неизвестных источников.
  2. Выберите способ перевода В настройках выберите способ перевода: подключение к удалённому серверу ImageTrans (укажите адрес сервера и пароль проекта) или локальный OCR на телефоне с последующим переводом через интерфейс, совместимый с OpenAI, либо MyMemory. При выборе MyMemory API-ключ не нужен.
  3. Настройте языковую пару Выберите исходный и целевой языки. Исходный язык «Авто» обрабатывается как японский, целевой «Авто» — как английский; можно указать их явно.
  4. Начните перевод Выберите изображение из галереи, сделайте фото, выберите папку или включите плавающее окно перевода скриншотов. Приложение распознает текст, переведёт его и вернёт перевод на изображение.
  5. Сохраните или поделитесь Сохраните перевод в галерею или поделитесь им; после завершения перевода папки можно сразу открыть папку с результатами.

Системные требования и ограничения

📱

Устройства arm64

Поддерживается Android 8.0 и новее. Библиотека локального OCR доступна только для arm64-v8a, что поддерживают практически все современные Android-телефоны. Эмуляторы x86_64 не могут запускать OCR.

🌐

Сеть

В локальном режиме OCR полностью выполняется на телефоне, а на API перевода отправляется только текст. Режиму сервера нужен доступ к вашему серверу ImageTrans; модели OCR для корейского, арабского, русского и тайского скачиваются при первом использовании.

🔋

Работа в фоне

Плавающее окно перевода скриншотов и сервер перевода для расширения зависят от работы foreground-сервиса. В некоторых китайских ROM нужно разрешить фоновую активность и отключить оптимизацию батареи.
