Puede ayudar a mejorar ImageTrans de las siguientes formas:

1. Traducir la documentación

	La documentación de ImageTrans está hecha con Sphinx y alojada en readthedocs.

	Repositorio de la documentación: <https://github.com/xulihang/ImageTrans-docs>

	Es necesario usar la herramienta de localización de Sphinx para extraer los archivos po y traducirlos.

2. Traducir la interfaz del software

	ImageTrans usa [B4XLocalizator](https://www.b4x.com/android/forum/threads/b4x-localizator-localize-your-b4x-applications.68751/) para realizar la localización, y es necesario traducir el archivo strings.xlsx. Una vez traducido, debe convertirse en strings.db para que el software lo utilice.
	
	Descargue strings.xlsx aquí: <https://github.com/xulihang/ImageTrans_l10n_en/releases/tag/strings>

3. Desarrollar complementos

	ImageTrans usa ABPlugin para desarrollar complementos. Código de los complementos existentes: <https://github.com/xulihang/ImageTrans_plugins>
	
4. Enviar sugerencias

	Visite la [página de issues](https://github.com/xulihang/ImageTrans-docs/issues) de la documentación para enviar sugerencias.
