Extensión de navegador ImageTrans

Traduce con un clic cualquier imagen de las páginas web; está pensada para cómics, pósteres, capturas de pantalla y otros casos similares. Haz clic con el botón derecho o usa el atajo de teclado para obtener la traducción al momento.

Gratis y de código abierto (GPL v2.0)
🌐 Añadir a Chrome 🦊 Añadir a Firefox 🧊 Añadir a Edge

¿Qué es la extensión de navegador ImageTrans?

La extensión de navegador ImageTrans lleva directamente a tu navegador la traducción de imágenes impulsada por IA. Detecta el texto de las imágenes de las páginas web (cómics, pósteres, capturas de pantalla, folletos, etc.) y lo sustituye automáticamente por la versión traducida.

Basándose en PaddleOCR y en el backend de la aplicación de escritorio ImageTrans, la extensión combina la tecnología OCR más avanzada con traducción automática neuronal para ofrecerte resultados precisos y ajustados al contexto.

Funciones principales

🖱️

Traducción con el botón derecho

Haz clic con el botón derecho en cualquier imagen de una página web, elige «Traducir imagen» y obtendrás al instante la versión traducida.

⌨️

Atajos de teclado

Pulsa Ctrl+Shift+F para traducir la imagen que está bajo el cursor, de forma rápida y eficaz.

🔄

Traducción automática

Si activas la traducción automática, las imágenes se traducirán al cargar la página. Ideal para leer cómics largos.

📸

Traducción de capturas de pantalla

Captura una región de la pantalla en el navegador para traducirla; es útil para imágenes que no se pueden descargar o para traducir solo una parte de la imagen.

🤖

Opciones de traducción flexibles

Combina cualquier backend de OCR (ImageTrans o PaddleOCR) con una API compatible con OpenAI (ChatGPT, Gemini, DeepSeek) o con los motores de traducción integrados para obtener los mejores resultados.

🀄

Anotaciones de pronunciación

Añade furigana al texto japonés y pinyin al texto chino: un gran aliado para quienes aprenden idiomas.

Cómo usarla

  1. Instala la extensión Ábrela en la Chrome Web Store, en los complementos de Firefox o en la tienda de complementos de Microsoft Edge y añádela. 📱 Móvil: en iOS puedes ejecutar las extensiones de Chrome o Firefox con el navegador Orion. En Android puedes usar Firefox para Android, Edge o el navegador Kiwi.
  2. Configura el backend Conéctate a un servidor ImageTrans, usa PaddleOCR integrado o configura tu propia clave de API compatible con OpenAI.
  3. Empieza a traducir Haz clic con el botón derecho en una imagen → «Traducir imagen». También puedes activar la traducción automática para traducir todas las imágenes al cargar la página, usar la función de captura de pantalla para traducir una parte de la pantalla, o usar la función de cámara para fotografiar y traducir en tiempo real. ¡Listo!

Cómo funciona

🔌 Con ImageTrans de escritorio (recomendado)

  • ImageTrans se encarga de todo el proceso: detección → OCR → eliminación del texto → traducción → renderizado
  • La mejor precisión, el mayor número de idiomas y muchas opciones de edición
  • La extensión envía la imagen a ImageTrans y muestra directamente el resultado final
  • Requiere que ImageTrans se ejecute en local o en un servidor

🧩 Sin ImageTrans (todo en el navegador)

  • La extensión realiza todo el proceso de forma independiente en el frontend: OCR (PaddleOCR) → traducción → renderizado
  • No requiere servidor ni instalar ningún software: totalmente autónoma
  • Gratuita y respetuosa con la privacidad
  • Precisión, velocidad y opciones de idioma más limitadas

Opciones de traducción

Los siguientes métodos de traducción están disponibles en ambos modos. Cuando se usa una API compatible con OpenAI junto con ImageTrans, ImageTrans solo se encarga del OCR; la traducción y el renderizado los realiza la extensión en el frontend.

🌐 Traducción integrada de ImageTrans

  • Disponible al conectarse a ImageTrans
  • Compatible con varios motores de traducción (Google, DeepL, Baidu, etc.)
  • Incluye memoria de traducción, gestión de terminología y búsqueda en corpus

🤖 API compatible con OpenAI

  • Usa ChatGPT, Gemini, DeepSeek o cualquier API compatible
  • Funciona con o sin ImageTrans: usa tu propia clave de API
  • Prompts personalizados y flexibles para una traducción más precisa
  • Con ImageTrans: ImageTrans solo hace el OCR y la extensión se encarga de la traducción y el renderizado

🆓 MyMemory (gratis)

  • API de traducción automática gratuita, sin clave
  • Ideal para traducciones rápidas y puntuales

Acerca de ImageTrans de escritorio

ImageTrans es un completo programa de escritorio para la traducción de imágenes asistida por ordenador. La extensión de navegador es ideal para traducciones rápidas e inmediatas, mientras que ImageTrans de escritorio te da el control total de todo el flujo de trabajo de traducción.

🎛️

Potentes opciones de personalización

Ajusta cada paso con precisión: elige entre varios motores de OCR, configura los algoritmos de detección y personaliza los parámetros de renderizado para adaptarte exactamente a tus necesidades.

✏️

Edición manual

Ajusta las regiones de texto, corrige los resultados del OCR, edita la traducción y afina la posición del texto: cuando la automatización no basta, tú tienes el control.

🎨

Exportación a PSD

Exporta las imágenes traducidas a archivos de Photoshop (PSD) con el texto en capas independientes, para entregarlas fácilmente a un diseñador y que las retoque.

📦

Procesamiento por lotes

Traduce cientos de imágenes de una vez. Permite importar y exportar datos mediante Excel, Word o XLIFF, integrándose sin problemas con otras herramientas de traducción.

¿Qué puedes traducir?

📚

Cómics y webtoons

Lee cómics, webtoons y fanarts traducidos en cualquier sitio web. La extensión está optimizada para los bocadillos y la disposición del texto de los cómics.

📋

Pósteres y folletos

Comprende rápidamente materiales promocionales, infografías y anuncios en otros idiomas.

📱

Capturas de pantalla y fotos

Usa la función de captura de pantalla para traducir una parte de una imagen o para traducir imágenes que no se pueden descargar de una página web, ¡todo dentro del navegador!

📝

Extraer texto de imágenes

Extrae texto de imágenes sin traducirlo. Útil para tareas de OCR, entrada de datos y casos de accesibilidad.
